## 1. 목표

RVTT의 씬은 Roblox Studio 밖에서 별도로 제작해 가져오는 것을 기본 흐름으로 삼지 않는다. DM이 RVTT 안에서 직접 제작하고 수정할 수 있어야 한다.

> 씬 편집기는 정밀한 3D 모델링 프로그램이 아니라, 블록스버그식 벽 툴처럼 빠른 입력과 자동 정리가 중심인 인게임 건축 도구다.

DM은 클릭과 드래그만으로 방, 복도, 계단과 소품을 만들 수 있어야 한다. 도구가 생성한 구조물은 시각 오브젝트뿐 아니라 이동 가능 표면, 차단 영역, 문 상태와 같은 이동 의미 데이터도 함께 제공해야 한다.

일반적인 던전과 건물 씬은 다음 흐름으로 제작되는 것을 목표로 한다.

```text
층 선택
→ 벽과 방 그리기
→ 문, 창문과 계단 삽입
→ 프리팹과 소품 배치
→ 재질과 조명 조정
→ 이동 데이터 자동 갱신
→ 테스트 플레이
→ 게시
```

## 2. 편집기의 기본 원칙

### 2.1 모든 제작은 인게임에서 수행한다

- DM 전용 씬 편집 모드에서 작업한다.
- 같은 Roblox Place 안에서 씬을 제작하고 저장한다.
- 구조적인 편집 중에는 라이브 세션을 일시정지한다.
- 세션 중 작은 변경은 빠른 편집으로 별도 처리한다.

### 2.2 배치 전에 항상 결과를 보여준다

모든 도구는 확정 전 로컬 미리보기를 제공한다.

- 배치될 위치
- 크기와 방향
- 스냅 결과
- 재질과 색상
- 예상 벽 연결과 문 구멍
- 이동 표면과 차단 의미
- 유효하지 않은 이유

유효한 배치는 정상 고스트로, 잘못된 배치는 경고 고스트로 표시한다.

### 2.3 같은 조작 규칙을 공유한다

도구마다 완전히 다른 조작법을 만들지 않는다.

기본 규칙:

- 클릭: 시작, 지점 지정 또는 배치
- 드래그: 크기와 범위 지정
- 추가 클릭: 연속 지점 추가
- 완료 입력: 현재 도형 확정
- 취소 입력: 현재 미리보기 취소
- 선택 후 핸들: 기존 결과 수정

정확한 키와 버튼 배치는 입력·UI 문서에서 확정한다.

### 2.4 시각 오브젝트와 의미 데이터를 함께 만든다

벽 도구는 벽 모델만 생성하지 않는다.

```text
벽 모델
+ 이동 차단 영역
+ 필요 시 시야 차단 정보
+ 벽 체인의 연결 데이터
```

바닥 도구는 다음을 함께 만든다.

```text
바닥 모델
+ 이동 가능 표면
+ 현재 층 정보
+ 기본 지형 비용
```

문, 계단, 물과 잔해도 같은 원칙을 사용한다.

### 2.5 결과는 다시 편집할 수 있어야 한다

도구 결과를 단순한 Part 묶음으로만 저장하지 않는다. 원본 파라미터를 보존한다.

예시:

```text
WallChain
- 지점 목록
- 높이
- 두께
- 재질
- 색상
- 문과 창문 슬롯
```

이후 벽의 끝점을 움직이거나 높이를 바꾸면 시각 구조와 이동 의미가 함께 다시 생성된다.

## 3. 공통 편집 기반

개별 건축 도구보다 먼저 다음 공통 기능이 필요하다.

### 3.1 선택 도구

- 단일 선택
- 박스 다중 선택
- 같은 그룹 선택
- 같은 프리팹 종류 선택
- 선택 항목 추가와 제외
- 잠긴 오브젝트 선택 방지

선택한 대상은 외곽선과 피벗으로 명확하게 표시한다.

### 3.2 이동, 회전과 크기 조절

- 축 이동
- 평면 이동
- 높이 이동
- 자유 회전과 각도 스냅 회전
- 허용된 오브젝트의 크기 조절
- 수치 직접 입력

벽, 방과 계단 같은 파라메트릭 오브젝트는 일반 Part 스케일 대신 전용 핸들을 표시한다.

### 3.3 스냅 시스템

모든 제작 도구가 하나의 스냅 시스템을 공유한다.

지원 후보:

- 선택적 위치 격자 스냅
- 각도 스냅
- 벽 끝점
- 벽 중간점
- 모서리
- 바닥 표면
- 오브젝트 피벗
- 현재 층 높이
- 같은 높이
- 인접 면

플레이 규칙의 5피트 격자와 편집 스냅은 별개다. 편집자는 필요에 따라 더 작은 stud 간격으로 배치할 수 있다.

### 3.4 층과 높이 관리자

건물과 복층 던전을 편하게 만들기 위해 명시적인 층 개념을 둔다.

- 현재 편집 층 선택
- 층 추가, 복제, 이름 변경과 삭제
- 층 기본 높이 설정
- 위층과 아래층 흐리게 표시
- 다른 층 잠금 또는 숨김
- 선택 항목을 다른 층으로 이동

벽과 바닥 도구는 기본적으로 현재 층에 배치된다.

### 3.5 실행 취소와 다시 실행

모든 편집 작업은 하나의 트랜잭션으로 기록한다.

예시:

- 벽 체인 하나 그리기
- 방 하나 만들기
- 문 하나 삽입하기
- 여러 소품을 한 번에 복제하기

한 번의 사용자 작업이 수십 개 Part를 생성해도 실행 취소는 한 번으로 처리한다.

### 3.6 복제, 삭제와 속성 복사

- 선택 복제
- 드래그 복제
- 제자리 복제
- 다중 삭제
- 재질과 색상 복사
- 프리팹 설정 복사
- 스포이드로 같은 에셋 또는 속성 선택

### 3.7 그룹, 잠금과 표시

- 오브젝트 그룹
- 그룹 단위 이동과 복제
- 선택 잠금
- 편집 중 숨김
- 카테고리별 표시
- 층별 표시

## 4. 1차 핵심 맵 제작 도구

다음 도구는 첫 번째 완성형 씬 편집기에 포함하는 것을 목표로 한다.

## 4.1 벽 도구

블록스버그식 벽 그리기를 핵심 기준으로 삼는다.

### 기본 조작

```text
시작점 클릭
→ 다음 지점 클릭
→ 연속 벽 생성
→ 완료 입력으로 벽 체인 확정
```

지원 기능:

- 직선 벽
- 연속 꺾인 벽
- 시작점으로 돌아오면 폐쇄된 벽 체인 생성
- 길이와 각도 표시
- 끝점, 모서리와 기존 벽 스냅
- 벽 높이, 두께, 재질과 색상 설정
- 벽 안쪽과 바깥쪽 방향 표시
- 기존 벽 끝점을 드래그해 수정
- 벽 중간에 지점 추가 또는 제거

### 자동 연결

- 맞닿은 벽 끝을 자동 결합
- 모서리의 작은 틈 제거
- 교차하는 벽의 접합 정리
- 겹치는 중복 벽 경고
- 같은 속성의 연속 직선 벽 병합

### 생성 결과

벽은 가능한 한 단순한 직선 구간 단위로 생성한다. 벽마다 개별 스크립트를 두지 않는다.

벽 도구는 동시에 다음을 생성한다.

- 시각 벽 구조
- 이동 차단 의미
- 선택적인 시야 차단 의미
- 문과 창문을 삽입할 수 있는 벽 슬롯

## 4.2 방·바닥 도구

바닥은 단순 사각형과 자유 다각형을 모두 지원한다.

### 사각형 방

```text
첫 모서리 클릭
→ 반대 모서리 드래그
→ 바닥 생성
→ 선택적으로 외곽 벽 자동 생성
```

옵션:

- 바닥만
- 바닥과 외벽
- 바닥, 외벽과 천장
- 현재 벽 높이 사용

### 자유형 바닥

여러 지점을 찍어 불규칙한 방, 동굴 발판과 다리를 만든다.

바닥 도구는 다음을 함께 생성한다.

- 바닥 시각 구조
- 이동 가능 표면
- 층과 높이 정보
- 기본 이동 비용

폐쇄된 벽 체인이 존재하면 내부 바닥 생성을 추천할 수 있다.

## 4.3 문과 창문 삽입 도구

문과 창문은 벽 위에 직접 삽입한다.

```text
문 프리팹 선택
→ 벽 위에 마우스 이동
→ 벽에 맞춰 자동 정렬
→ 클릭하여 삽입
```

문을 삽입하면 벽에 구멍을 내기 위해 벽 구간을 안전하게 분할하거나 문용 모듈로 교체한다.

문이 생성하는 정보:

- 문 시각 모델
- 열림과 닫힘 상태
- 닫혔을 때의 동적 이동 차단
- 잠금과 상호작용 정보
- 선택적인 시야 차단 상태

창문은 기본적으로 이동을 막지만 시야 처리와 엄폐 정보는 별도 설정한다.

## 4.4 계단과 경사로 도구

첫 단계와 끝 단계를 지정해 계단 또는 경사로를 만든다.

```text
아래 지점 선택
→ 위 지점 선택
→ 폭과 방향 조정
→ 계단 또는 경사 선택
```

자동 처리:

- 현재 층과 목표 층 높이 계산
- 계단 수 또는 경사 길이 계산
- 위아래 바닥과 스냅
- 이동 표면과 층간 연결 생성
- 머리 공간과 출구 막힘 검사

초기 버전에서는 직선 계단과 직선 경사로를 우선한다. 꺾인 계단과 나선 계단은 후속 도구로 둔다.

## 4.5 프리팹 배치 도구

가구, 나무, 바위, 상자, 조명과 장식을 배치한다.

기능:

- 에셋 검색과 카테고리
- 최근 사용
- 즐겨찾기
- 하단 퀵 바 등록
- 배치 고스트
- 표면 자동 정렬
- 바닥, 벽과 천장 부착 유형
- 회전 스냅
- 연속 배치
- 무작위 회전과 크기 범위

프리팹은 이동 프로필과 상호작용 프로필을 포함할 수 있다.

예시:

- 큰 책상: 이동 차단
- 작은 컵: 내비게이션 제외
- 횃불: 벽 부착 + 조명
- 얕은 물: 이동 표면 + 험지

## 4.6 기본 파트와 사용자 프리셋 도구

DM이 간단한 형태를 즉석에서 만들 수 있어야 한다.

기본 형태:

- 블록
- 원기둥
- 쐐기
- 평면

조작:

- 생성
- 크기 조절
- 색상과 재질 변경
- 피벗 설정
- 이동 프로필 선택
- 프리셋으로 저장

예를 들어 `1×4×4 stud, 목재, 파란색` 블록을 사용자 프리셋으로 저장하고 이후 에셋처럼 배치할 수 있다.

프리셋 저장 시 다음도 포함한다.

- 시각 속성
- 기본 크기
- 스냅 기준
- 배치 유형
- 이동 의미
- 필요 시 조명 또는 상호작용 설정

## 4.7 재질과 페인트 도구

오브젝트를 다시 만들지 않고 외형을 빠르게 변경한다.

- 단일 오브젝트 색상 변경
- 재질 변경
- 같은 그룹 전체 적용
- 연결된 벽 체인 전체 적용
- 방 내부 또는 외부 면 적용
- 스포이드
- 최근 사용 재질
- 재질 프리셋

벽의 앞면과 뒷면에 다른 마감재를 적용하는 기능은 후속 확장으로 둔다.

## 4.8 지우개 도구

지우개는 단순 삭제 단축 기능이다.

- 클릭 삭제
- 드래그 범위 삭제
- 카테고리 필터
- 현재 층만 삭제
- 잠긴 오브젝트 보호

벽의 일부를 지울 때는 벽 체인 데이터가 깨지지 않도록 해당 구간만 제거하고 양쪽 체인을 다시 정리한다.

## 5. 2차 확장 도구

핵심 건축 흐름을 완성한 뒤 다음 도구를 추가한다.

### 5.1 울타리와 난간 도구

벽 도구와 같은 선 그리기 입력을 재사용한다.

- 울타리
- 난간
- 밧줄
- 절벽 경계
- 장식 테두리

프리팹을 일정 간격으로 반복 배치하며, 이동 차단 여부를 프로필로 결정한다.

### 5.2 선형·배열 배치 도구

프리팹을 규칙적으로 반복한다.

- 직선 배열
- 원형 배열
- 간격 지정
- 개수 지정
- 경로를 따라 배치

용도:

- 기둥
- 횃불
- 나무 울타리
- 시장 가판대
- 책장

### 5.3 산포 브러시

영역을 칠해 소품을 무작위로 배치한다.

- 풀
- 작은 돌
- 잔해
- 나무
- 버섯

밀도, 크기, 회전과 최소 간격을 설정한다. 결과는 하나의 산포 그룹으로 관리하며 개별 오브젝트를 모두 따로 편집할 필요가 없게 한다.

### 5.4 길과 도로 도구

선을 그으면 폭을 가진 길을 만든다.

- 직선과 곡선 경로
- 폭 설정
- 재질
- 가장자리 장식
- 지형 비용

동굴 통로, 흙길, 강과 운하에도 같은 기반을 재사용할 수 있다.

### 5.5 지형 스탬프 도구

초기에는 완전한 자유 지형 조각보다 검증된 지형 조각을 배치하는 방식을 우선한다.

- 언덕
- 절벽
- 동굴 벽
- 바위 지대
- 강바닥
- 지면 패치

각 스탬프는 이동 프로필을 포함하며 배치 후 크기와 높이를 제한적으로 조정할 수 있다.

Roblox Terrain을 직접 조각하는 고급 브러시는 이후 성능과 저장 구조를 검증한 뒤 추가한다.

### 5.6 지붕 도구

벽 체인 또는 방 외곽을 선택해 지붕을 생성한다.

초기 후보:

- 평지붕
- 단순 박공지붕
- 한쪽 경사지붕

복잡한 교차 지붕 자동 생성은 구현 난도가 높으므로 후순위로 둔다.

### 5.7 청사진과 구역 프리셋

선택한 구조와 소품을 하나의 재사용 가능한 청사진으로 저장한다.

예시:

- 작은 여관 방
- 경비 초소
- 캠프
- 시장 가판대 묶음
- 던전 복도 모듈

청사진은 내부 오브젝트 관계, 이동 프로필과 문 연결을 유지한다.

## 8. 도구 구현 구조

도구가 Workspace를 제각각 직접 수정하지 않는다.

### 8.1 공통 도구 인터페이스

각 도구는 개념적으로 다음 책임을 가진다.

```text
입력 해석
미리보기 생성
스냅 요청
유효성 검사
편집 명령 생성
서버 확정 요청
완료 또는 취소
```

공통 기능은 별도 서비스로 분리한다.

- SelectionService
- SnapService
- PreviewService
- SceneCommandService
- UndoService
- PrefabRegistry
- SceneValidationService
- NavigationBuildService

각 도구가 선택, 스냅과 실행 취소를 따로 구현하지 않는다.

### 8.2 명령과 트랜잭션

편집 결과는 `생성`, `수정`, `삭제` 명령으로 표현한다.

클라이언트는 미리보기를 표시하고, 서버는 권한과 입력을 검증한 뒤 씬 데이터를 변경한다.

```text
사용자 입력
→ 클라이언트 미리보기
→ SceneCommand 생성
→ 서버 검증
→ 씬 원본 데이터 변경
→ 영향 오브젝트 재생성
→ 이동 데이터 부분 갱신
→ 참가자 동기화
```

### 8.3 원본 데이터와 생성 결과 분리

씬 저장의 기준은 단순 Part 목록이 아니라 편집 가능한 원본 데이터다.

예시 원본:

- WallChain
- FloorPolygon
- DoorInstance
- StairConnection
- PrefabInstance
- ScatterGroup
- GameplayZone

시각 Part와 이동 의미 데이터는 원본에서 생성되는 결과다.

이 구조를 사용하면 다음이 가능하다.

- 벽 끝점 수정
- 층 높이 변경
- 프리팹 버전 갱신
- 이동 데이터 재생성
- 오브젝트 수 최적화
- 저장 스키마 마이그레이션

## 9. 성능 원칙

- 편집 고스트는 기본적으로 해당 DM 클라이언트에만 생성한다.
- 확정 시 여러 Part 변경을 하나의 배치 작업으로 처리한다.
- 오브젝트마다 Script를 붙이지 않는다.
- 벽은 불필요하게 짧은 Part 수백 개로 분할하지 않는다.
- 같은 종류의 대량 장식은 산포 그룹과 인스턴스 데이터로 관리한다.
- 씬 변경 시 전체 이동 데이터를 다시 만들지 않고 영향 영역만 갱신한다.
- 다른 층과 멀리 떨어진 구역은 편집 표시와 선택 질의를 줄인다.
- 에셋 브라우저는 썸네일과 메타데이터를 지연 로드한다.
- 게시 전에 오브젝트 수, 메시 수, 조명 수와 이동 데이터 비용을 검사한다.

자동 최적화가 원본의 편집 가능성을 파괴해서는 안 된다. 게시용 결과를 병합하거나 단순화하더라도 편집 원본은 유지한다.

## 10. 1차 구현 범위

첫 번째 구현 목표는 던전, 집과 마을 내부를 실제로 제작할 수 있는 최소 완성 세트다.

### 필수 기반

1. 선택과 다중 선택
2. 이동, 회전과 제한된 크기 조절
3. 스냅 시스템
4. 층 관리자
5. 실행 취소와 다시 실행
6. 복제, 삭제, 그룹과 잠금
7. 에셋 브라우저와 퀵 바

### 필수 제작 도구

1. 벽 도구
2. 사각형 방·바닥 도구
3. 자유형 바닥 도구
4. 문과 창문 삽입
5. 직선 계단과 경사로
6. 프리팹 배치
7. 기본 파트와 사용자 프리셋
8. 재질과 페인트
9. 지우개

### 필수 마무리

1. 이동 데이터 자동 생성과 부분 갱신
2. 가상 토큰 자동 주행 검사
3. 씬 저장과 불러오기
4. 테스트 토큰 이동
5. 게시 전 성능과 오류 검사

이 범위가 완성되기 전에는 지붕 자동 생성, 자유 지형 조각과 복잡한 절차적 건물 생성기를 우선하지 않는다.

## 11. 확정하는 방향

1. 씬은 RVTT 인게임 편집기에서 직접 제작한다.
2. 사용 경험은 블록스버그식 빠른 건축 도구를 기준으로 한다.
3. 도구는 배치 전 고스트와 유효성 피드백을 제공한다.
4. 모든 도구가 공통 선택, 스냅, 명령, 실행 취소와 검증 구조를 사용한다.
5. 벽, 바닥, 문과 계단은 파라미터를 보존하는 편집 가능한 오브젝트다.
6. 제작 도구는 시각 결과와 이동 의미 데이터를 함께 생성한다.
7. 에셋과 사용자 프리셋은 이동 프로필을 포함할 수 있다.
8. 자동 이동 데이터 생성과 검사는 일반 제작 흐름에 포함한다.
9. 씬 저장 기준은 생성된 Part가 아니라 편집 가능한 원본 씬 데이터다.
10. 첫 구현은 벽, 방, 문, 계단, 프리팹과 기본 편집 기반에 집중한다.
