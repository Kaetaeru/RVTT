# 45. 자유 전술 카메라 모델

- 상태: 확정
- 즉시 구현 명세 가능성: `READY_WITH_DEFAULTS`
- 남은 기본값: 회전 감도, 줌 범위, 벽 충돌 여유 거리, 연출별 최대 강제 시간
- 관련 결정: ADR-0050

## 기본 조작

- WASD: 전투 및 일반 카메라 모드에서 평면 이동
- 마우스 중간 버튼 또는 지정 입력: 회전
- 휠: 확대·축소
- 선택 Actor 초점 이동
- 추적 켜기·끄기
- 카메라 높이 조절

탐험에서 토큰 WASD 직접 이동을 사용하는 동안에는 카메라 이동 보조 입력을 별도로 제공하고, 카메라 추적을 켤 수 있다.

## 카메라 상태

```text
Free
FollowingActor
FocusingTarget
PresentationControlled
RestoringPrevious
```

연출 카메라가 끝나면 이전 카메라 transform, 추적 대상과 ViewY 상태를 복원한다.

## 우선순위

```text
시스템 복구·오류
> 주사위 공개
> 필수 반응·DM 승인
> 중요 PresentationRecipe
> DM 카메라 유도
> 저널·오브젝트 초점 이동
> Actor 추적
> 자유 카메라
```

낮은 우선순위 요청은 중단되거나 대기하고, 높은 우선순위 요청이 끝나면 스택에서 복귀한다.

## ViewY와 가림

- ViewY는 사용자별 로컬 보기 상태다.
- 기준 높이보다 위의 시각 파츠를 투명화하고 마우스 쿼리에서 제외한다.
- 이동·시야·충돌·Fog 권위 상태는 바꾸지 않는다.
- 지붕·벽 가림 보정은 화면 표시 전용이며 비밀 정보를 공개하지 않는다.

## 북마크와 링크

카메라 북마크는 sceneId, pivot, orientation, zoom, ViewY를 저장한다. 저널의 Actor·오브젝트·방 링크는 권한을 확인한 뒤 대상을 강조하고 카메라를 이동한다.

## DM 유도

DM은 다음을 선택한다.

- 초점 이동 제안: 플레이어가 거절 가능
- 짧은 연출 카메라: 일정 시간 또는 Q로 종료
- 세션 일시정지 연출: 입력 잠금 가능

플레이어 카메라를 무기한 강제 고정하지 않는다.
