# 05. 이동 의미 레이어 자동 제작 파이프라인

- 상태: 초안

## 1. 목표

씬 제작자가 이동 가능 표면, 차단 영역과 험지를 맵 전체에 수동으로 그리는 방식을 기본으로 삼지 않는다.

> 일반적인 씬은 한 번의 `이동 데이터 만들기`로 플레이 가능한 상태가 되어야 하며, DM은 시스템이 확신하지 못한 예외만 검토한다.

수동 브러시와 차단 도구는 기본 제작 방식이 아니라 자동 처리의 예외를 수정하는 안전장치다.

---

## 2. 기본 제작 흐름

```text
프리팹 이동 프로필
→ 장면 자동 분석
→ 이동 의미 레이어 자동 생성
→ 가상 토큰 자동 주행 검사
→ 확실한 오류 자동 보정
→ 애매한 문제만 검토함에 표시
→ 필요할 때만 수동 수정
→ 게시 전 최종 검사
```

DM이 보는 기본 버튼은 하나로 통합한다.

```text
이동 데이터 만들기 / 갱신
```

버튼을 누르면 생성, 검사와 안전 보정을 순서대로 수행한다.

---

## 3. 1단계: 프리팹 이동 프로필

에셋과 프리팹은 가능한 한 이동 의미를 미리 포함한다.

예시:

| 프리팹 | 기본 이동 프로필 |
|---|---|
| 바닥 | 이동 가능 표면 |
| 벽 | 이동 차단 |
| 문 | 상태 연동형 차단 |
| 계단 | 이동 표면 + 위아래 연결 |
| 경사로 | 연결된 이동 표면 |
| 작은 장식 | 내비게이션 제외 |
| 큰 책상 | 이동 차단 |
| 잔해 | 험지 또는 차단 |
| 안개 VFX | 내비게이션 제외 |
| 얕은 물 | 이동 표면 + 험지 |

씬에 프리팹을 배치하면 해당 이동 프로필도 함께 배치된다.

DM이 동일한 벽, 문과 계단을 놓을 때마다 이동 의미를 다시 설정하지 않는다.

### 프로필 덮어쓰기

특수한 장면에서는 인스턴스 단위로 기본 프로필을 덮어쓸 수 있다.

예시:

- 평소에는 차단물인 책상을 이번 장면에서는 넘을 수 있게 설정
- 일반 물을 험지가 아닌 통과 불가 깊은 물로 변경
- 무너진 벽 프리팹을 차단물 대신 험지로 변경

덮어쓰기는 원본 프리팹을 바꾸지 않고 현재 씬에만 적용한다.

---

## 4. 2단계: 장면 자동 분석과 이동 레이어 생성

시스템은 프리팹 이동 프로필을 우선 사용하고, 프로필이 없는 구조물은 제한적으로 분석한다.

자동 생성 대상:

- 이동 가능한 바닥과 지형 표면
- 고정 벽과 큰 구조물의 단순 차단 영역
- 문 프리팹의 열림·닫힘 차단 상태
- 계단과 경사로의 표면 연결
- 프리팹에 정의된 험지
- 플레이어 시작 지점과 주요 상호작용 지점
- 내비게이션 제외 태그가 있는 연출 오브젝트

### 자동 추론의 제한

시스템은 모델 이름이나 투명도만 보고 중요한 이동 의미를 임의로 결정하지 않는다.

우선순위는 다음과 같다.

1. 씬 인스턴스의 명시적 덮어쓰기
2. 프리팹 이동 프로필
3. 장면 제작 도구가 지정한 분류
4. 제한적인 형태 분석
5. 알 수 없음으로 분류

확실하지 않은 대상을 억지로 차단물이나 험지로 추측하지 않는다.

---

## 5. 3단계: 자동 주행 검사

이 단계가 단순 자동 생성 뒤에 추가되는 자동화다.

시스템은 실제 플레이 토큰을 움직이지 않고 여러 크기의 가상 검사 토큰으로 생성된 이동 데이터를 시험한다.

기본 검사 토큰:

- Small
- Medium
- Large

필요하면 Huge 이상은 별도 검사로 실행한다.

### 검사 시작점

다음 위치에서 주행 검사를 시작한다.

- 플레이어 진입 지점
- DM이 지정한 주요 방과 구역
- 문 양쪽
- 계단과 경사로의 양 끝
- 상호작용 오브젝트 주변
- 장면 전환 지점
- 전투 배치 지점

### 자동으로 찾는 문제

- 바닥 사이의 매우 작은 끊김
- 걸을 수 있어야 할 방이 고립됨
- 열린 문이 여전히 길을 막음
- 닫힌 문을 우회해 통과할 수 있음
- 계단 아래와 위가 연결되지 않음
- 경사로 끝에서 다른 표면으로 넘어가지 못함
- 얇은 장식물 때문에 길이 끊김
- 투명 VFX 또는 선택 표시가 잘못 포함됨
- 작은 이동 표면 조각이 공중에 남음
- 차단 영역이 중복되어 통로가 의도보다 좁아짐
- Medium 토큰은 지나가지만 Large 토큰은 지나가지 못하는 통로
- 주요 상호작용 지점에 접근할 수 없음
- 시작 지점에서 플레이 영역으로 나갈 수 없음
- 험지가 이동 표면 밖에 생성됨
- 같은 위치에 서로 충돌하는 이동 의미가 겹침

---

## 6. 4단계: 안전 자동 보정

검사 결과 중 의도가 명확하고 되돌리기 쉬운 문제는 자동으로 고친다.

### 자동 보정 가능한 예시

- 설정한 허용치보다 작은 바닥 틈 연결
- 아주 작은 고립 이동 표면 제거
- 동일 프리팹에서 중복 생성된 차단 영역 합치기
- 문 프리팹의 차단 영역을 문 상태와 다시 연결
- 계단 프리팹의 명확한 위아래 연결 스냅
- VFX, 핑, 선택 원과 편집 기즈모를 내비게이션에서 제외
- 같은 유형의 겹치는 험지 영역 정리
- 표면 경계의 작은 수치 오차 정리

### 자동으로 고치지 않는 예시

- 벽을 뚫어 통로를 새로 만드는 것
- 큰 가구를 장식인지 차단물인지 임의로 결정하는 것
- 절벽을 걸을 수 있는 경사로로 바꾸는 것
- 방 전체를 이동 가능 또는 불가능으로 뒤집는 것
- 여러 층 중 어느 층을 연결할지 불명확한 경우
- 험지의 규칙적 의미가 불명확한 경우

자동 보정은 씬 제작자의 의도를 추측해 큰 구조를 바꾸지 않는다.

모든 보정은 한 묶음으로 기록하여 한 번에 실행 취소할 수 있어야 한다.

---

## 7. 신뢰도와 검토함

자동 생성과 검사 결과에는 내부 신뢰도를 둔다.

| 상태 | 의미 | DM에게 보이는 처리 |
|---|---|---|
| 확정 | 프리팹 프로필 또는 명시 설정으로 판단 | 자동 적용, 기본적으로 숨김 |
| 보정됨 | 안전 규칙으로 자동 수정 | 결과 요약에서 확인 가능 |
| 검토 필요 | 두 가지 이상의 해석 가능 | 검토함에 표시 |
| 오류 | 플레이를 방해하는 명확한 문제 | 게시 전 해결 필요 |

DM에게 맵 전체를 보여주고 직접 찾게 하지 않는다. `검토 필요`와 `오류` 위치만 순서대로 안내한다.

검토 항목을 선택하면 카메라가 해당 위치로 이동하고 다음을 보여준다.

- 문제 위치
- 예상된 의미
- 현재 생성 결과
- 자동 판단을 보류한 이유
- 추천 수정 선택지

예시:

```text
계단 상단 연결을 확정할 수 없습니다.

추천:
1. 위층 바닥 A에 연결
2. 위층 발코니 B에 연결
3. 연결하지 않음
```

DM은 긴 속성 패널을 직접 조작하기보다 추천 선택지 중 하나를 고른다.

---

## 8. 수동 수정 도구

자동 처리 뒤에도 필요한 경우 다음 도구를 사용한다.

- 이동 가능 표면 브러시
- 이동 표면 지우개
- 선·박스·자유 영역 차단 도구
- 험지 브러시
- 계단과 층간 연결 도구
- 내비게이션 제외 지정
- 동적 차단물과 오브젝트 상태 연결
- 테스트 토큰

수동 수정은 원본 자동 생성 결과를 파괴적으로 덮어쓰지 않고 `씬 이동 오버라이드`로 기록한다.

씬을 다시 자동 생성해도 명시적으로 만든 수동 오버라이드는 보존한다. 다만 오버라이드 대상이 삭제되었거나 구조가 크게 바뀌면 검토함에 올린다.

---

## 9. 테스트 토큰과 핵심 경로

DM은 필요한 경우 테스트 토큰으로 직접 경로를 확인할 수 있다.

더 나아가 씬에 `핵심 경로`를 지정할 수 있다.

예시:

- 입구 → 보스방
- 입구 → 2층 계단
- 감옥 → 출구
- 플레이어 시작 지점 → 주요 NPC

자동 검사는 씬을 갱신할 때마다 핵심 경로가 여전히 유효한지 확인한다.

핵심 경로가 끊기면 일반 경고가 아니라 게시 차단 오류로 처리할 수 있다.

---

## 10. 부분 갱신

오브젝트 하나를 옮길 때마다 씬 전체 자동 생성을 다시 실행하지 않는다.

변경 영역 주변만 다음 순서로 갱신한다.

```text
변경 영역 확인
→ 해당 영역의 이동 의미 재생성
→ 인접 연결 확인
→ 해당 영역을 지나는 검사 경로 재실행
→ 안전 보정
→ 검토함 갱신
```

전체 생성은 다음 상황에서 수행한다.

- 처음 이동 데이터를 만드는 경우
- 대규모 지형 변경
- 씬 좌표계 또는 스케일 변경
- 프리팹 이동 프로필의 대규모 변경
- DM이 명시적으로 전체 재생성을 요청한 경우

---

## 11. 게시 결과

자동 처리 후 씬 상태를 세 단계로 표시한다.

### 준비 완료

- 치명적 오류 없음
- 핵심 경로 정상
- 검토 필요 항목 없음 또는 비차단 경고만 존재

DM은 이동 레이어 화면을 열지 않고 바로 게시할 수 있다.

### 검토 권장

- 플레이는 가능함
- 시스템이 확정하지 못한 선택지가 존재
- 게시할 수 있지만 문제 위치가 요약됨

### 게시 불가

- 플레이어 시작 지점이 고립됨
- 핵심 경로가 끊김
- 문 또는 계단 연결에 치명적 오류
- 이동 데이터 생성 실패

DM이 직접 맵 전체를 검사하는 대신 게시 결과와 문제 위치만 확인한다.

---

## 12. 사용자 경험 예시

```text
1. DM이 집, 벽, 문, 계단과 가구를 배치한다.
2. `이동 데이터 만들기`를 누른다.
3. 프리팹 프로필과 장면 구조로 이동 레이어가 생성된다.
4. Small, Medium, Large 가상 토큰이 자동으로 주요 구역을 검사한다.
5. 작은 틈, 중복 차단과 VFX 포함 오류가 자동 보정된다.
6. 시스템이 결과를 `준비 완료`로 표시한다.
7. DM은 이동 레이어를 직접 수정하지 않고 씬을 게시한다.
```

애매한 계단 연결 하나만 남았다면:

```text
1. 결과가 `검토 권장: 1건`으로 표시된다.
2. DM이 검토 항목을 연다.
3. 카메라가 계단으로 이동한다.
4. 추천된 위층 바닥을 선택한다.
5. 해당 구역만 재검사된다.
6. 결과가 `준비 완료`로 바뀐다.
```

## 13. 성능 원칙

- 자동 생성과 주행 검사는 편집·게시 단계에서 실행한다.
- 실제 세션 중 매 프레임 검사하지 않는다.
- 가상 토큰은 시각 모델과 물리 객체를 생성하지 않는 데이터 검사다.
- 변경된 영역과 영향을 받는 경로만 다시 계산한다.
- 반복되는 프리팹 결과는 캐시할 수 있어야 한다.
- 자동 보정 전후 결과를 비교하고 불필요한 재계산을 피한다.
- 검사 작업이 실패해도 기존의 마지막 정상 이동 데이터는 보존한다.

---

## 14. 확정하는 방향

1. 수동 이동 레이어 제작은 기본 흐름이 아니다.
2. 프리팹은 가능한 한 기본 이동 프로필을 포함한다.
3. 한 번의 명령으로 생성, 검사와 안전 보정을 수행한다.
4. 자동 생성 뒤 가상 토큰 주행 검사를 실행한다.
5. 확실하고 되돌릴 수 있는 오류만 자동 보정한다.
6. 애매한 문제는 맵 전체가 아니라 검토함으로 안내한다.
7. 수동 수정은 자동 결과 위의 오버라이드로 보존한다.
8. 일반적인 씬의 목표 상태는 DM의 이동 레이어 수동 작업 없이 `준비 완료`가 되는 것이다.
9. 씬 수정 후에는 변경 영역만 부분 갱신한다.
10. 게시 전 핵심 경로와 시작 지점의 접근성을 자동 검사한다.

---

## 15. 후속 결정

다음은 구현 기획에서 별도로 확정한다.

1. 자동으로 연결할 수 있는 최대 표면 틈 허용치
2. 안전 자동 보정과 검토 필요를 나누는 신뢰도 기준
3. 기본 검사 지점과 핵심 구역 자동 감지 방식
4. Small, Medium, Large 점유 범위의 정확한 크기
5. 프리팹 이동 프로필의 저장 형식
6. 자동 생성에 사용할 내비게이션 데이터 구조
7. 대형 씬의 검사 분할과 작업 진행 표시
8. 비차단 경고와 게시 차단 오류의 정확한 목록
