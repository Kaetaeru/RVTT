## 1. 문서 목적

RVTT는 물질 구성요소를 사용하는 캠페인과 사용하지 않는 캠페인을 모두 지원한다.

주문 콘텐츠는 항상 구조화된 음성, 동작과 물질 구성요소 데이터를 가진다. 그러나 물질 구성요소를 실제 시전 제한과 인벤토리 비용으로 적용할지는 캠페인 규칙이 결정한다.

```text
SpellDefinition.materialRequirements
+ CampaignRules.spellcasting.materialComponentMode
→ 이번 시전의 유효 물질 구성요소 요구
```

이 정책은 주문 정의를 변경하지 않고 규칙 해석 단계에서 적용한다.

---

## 2. 캠페인 설정

```text
CampaignRules
└─ spellcasting
   └─ materialComponentMode: ignore | enforce
```

- 기본값: `ignore`
- 적용 범위: 캠페인 전체
- 변경 권한: DM
- 플레이어별 예외: 지원하지 않음

캠페인 생성 화면과 캠페인 규칙 설정에서 다음처럼 표시한다.

```text
물질 구성요소
○ 무시
  주문시전 도구, 재료 가치와 소비 여부를 검사하지 않습니다.

○ 사용
  공식 규칙에 따라 도구와 실제 재료를 검사하고 소비합니다.
```

---

## 3. ignore 모드

`ignore` 모드는 주문의 `M` 요구 전체를 실행 판정에서 제거한다.

```text
원본 요구: V, S, M
캠페인 정책: ignore
유효 요구: V, S
```

제거되는 검사:

- 주문시전 도구와 구성요소 주머니
- 가격 없는 일반 재료
- 가격 있는 재료
- 소비되는 재료
- 고유 물체와 재료 상태
- 물질 구성요소용 손과 조작 슬롯
- 재료 인벤토리 예약과 소비

유지되는 검사:

- 음성 가능 여부
- 동작을 수행할 조작 슬롯
- 시전 경로 자체가 요구하는 아이템
- 주문 슬롯, 무료 시전과 아이템 충전
- 행동 경제
- 대상, 사거리, 효과선과 집중

### 아이템 시전과의 구분

물질 구성요소를 무시한다고 아이템 시전 비용이 사라지지는 않는다.

```text
완드의 주문 시전
├─ 원본 주문의 M 요구: 무시
├─ 완드 접근과 손 사용: 유지
└─ 완드 충전 소비: 유지
```

### 재료 아이템

재료 아이템은 일반 인벤토리 자산으로 존재할 수 있다. 다만 `ignore` 모드에서는 주문 엔진이 이를 자동 검사하거나 소비하지 않는다.

서사, 거래, 제작과 퀘스트에서 재료 아이템을 사용하는 것은 별도 시스템이 결정한다.

---

## 4. enforce 모드

`enforce` 모드에서는 `15-spell-components-and-material-inventory-contract.md`를 적용한다.

```text
원본 구성요소 요구
→ 주문 경로와 특성의 Override 적용
→ 음성·동작 가능 여부 검사
→ 도구·주머니·실제 재료 후보 검색
→ 손 사용과 아이템 접근 계획 생성
→ 소비 재료 예약
→ CastCostPlan에 포함
```

주요 규칙:

- 가격이 없고 비소모인 재료는 유효한 도구나 주머니로 대체 가능
- 가격 있는 재료는 실제 인벤토리 자산 필요
- 소비 재료는 시전 확정 시 원자적으로 소비
- 금화 자동 차감으로 재료 소유를 대신하지 않음
- DM의 일회성 대체 재료 승인은 구조화된 Override로 기록

---

## 5. 공통 실행 흐름

```text
시전 시작
→ 캠페인 규칙 revision과 materialComponentMode 스냅샷
→ SpellDefinition과 SpellCastRoute 조회
→ 유효 구성요소 요구 계산
→ ComponentSatisfactionPlan 생성
→ CastCostPlan 생성
→ 서버 재검증과 확정
```

### ignore의 ComponentSatisfactionPlan

물질 구성요소 배열을 빈 요구로 해석하되 정책 적용 사실을 기록한다.

```text
ComponentSatisfactionPlan
├─ policyMode: ignore
├─ verbalSatisfaction
├─ somaticSlotAssignments
├─ materialSatisfiers: []
├─ inventoryReservations: []
└─ appliedPolicy: campaign.material-components.ignore
```

원본 주문 데이터의 `materials` 배열을 삭제하거나 런타임에서 수정하지 않는다.

### enforce의 ComponentSatisfactionPlan

도구, 실제 재료, 손 배정과 예약을 모두 포함한다.

---

## 6. 설정 변경

DM은 캠페인 규칙 설정에서 모드를 변경할 수 있다.

변경 작업:

```text
현재 캠페인 revision 확인
→ DM 권한 검증
→ 새 모드 검증
→ 캠페인 설정 저장
→ revision 증가
→ 규칙 변경 로그 기록
→ 관련 시전 가능 여부 캐시 무효화
```

진행 중인 실행은 생성 당시의 정책 스냅샷을 유지한다.

- 이미 예약된 재료가 모드 변경으로 갑자기 해제되지 않는다.
- 진행 중인 시전이 갑자기 새 재료를 요구하지 않는다.
- 새로 시작하는 시전부터 변경된 정책을 사용한다.

모드 변경은 과거 소비를 환불하거나 인벤토리 항목을 자동 생성·삭제하지 않는다.

---

## 7. UI 표현

주문 카드에는 원본 `V`, `S`, `M` 정보를 계속 표시할 수 있다.

`ignore` 모드에서는 물질 구성요소에 캠페인 규칙 표시를 붙인다.

```text
[V] [S] [M]
물질 구성요소: 캠페인 규칙으로 무시됨
```

시전 불가 사유에는 무시된 물질 요구를 포함하지 않는다.

```text
시전 불가
- 침묵 영역으로 음성 구성요소를 사용할 수 없음
```

다음과 같은 메시지는 `ignore` 모드에서 나오지 않는다.

```text
- 주문시전 도구가 없음
- 300gp 다이아몬드가 없음
- 사용할 구성요소 주머니가 없음
```

캠페인 설정 변경 화면에서는 `enforce`로 전환하면 고가·소비 재료가 실제로 필요해진다는 점을 명시한다.

---

## 8. 서버 검증

서버는 다음을 검증한다.

- 캠페인에 저장된 모드와 revision이 유효한가
- 실행이 생성 당시 정책 스냅샷을 사용하고 있는가
- 클라이언트가 임의로 정책을 바꾸지 않았는가
- `ignore`에서 물질 재료 예약이나 소비가 생성되지 않았는가
- `enforce`에서 `ADR-0021`의 전체 검증을 통과했는가
- 설정 변경 요청자가 DM 권한을 가졌는가

클라이언트 시전 요청에는 `ignoreMaterials` 같은 권위 플래그를 두지 않는다.

---

## 9. 캐시와 갱신

모드가 변경되면 다음 캐시를 영향 범위에 따라 무효화한다.

- 주문별 현재 시전 가능 여부
- ComponentSatisfactionPlan 미리보기
- 주문시전 도구와 재료 부족 경고
- 행동 UI의 비활성 사유

`ignore` 모드에서는 재료 인벤토리 변화가 주문 시전 가능 여부 캐시를 갱신하지 않는다.

`enforce` 모드에서는 도구 장착, 재료 이동과 수량 변화가 관련 주문만 다시 평가하게 한다.

---

## 10. 명시적인 비목표

- 플레이어마다 다른 물질 구성요소 규칙을 제공하지 않는다.
- 주문마다 캠페인 설정을 개별적으로 끄고 켜지 않는다.
- `ignore` 모드가 음성이나 동작 구성요소까지 제거하지 않는다.
- `ignore` 모드가 주문 슬롯, 아이템 충전이나 행동 비용을 제거하지 않는다.
- `ignore` 모드에서 원본 주문 콘텐츠의 물질 구성요소 데이터를 삭제하지 않는다.
- 설정 변경으로 과거에 소비한 재료를 자동 환불하지 않는다.

---

## 11. 다음 단계

주문 획득, 주문책, 시전 경로, 자원 결제와 구성요소 정책의 기본 경계가 정해졌다.

다음은 **주문의 대상 지정과 영역 템플릿 공통 규약**을 설계한다.

- 자신, 단일 대상, 복수 대상, 지점과 물체
- 원뿔, 선, 구체, 원통과 벽
- 거리, 시야, 효과선과 엄폐
- 아군·적·생물 유형과 자발적 대상 조건
- 시전 레벨에 따른 대상 수와 영역 크기 변화
- 대상 선택 이후 상태 변화에 대한 서버 재검증
