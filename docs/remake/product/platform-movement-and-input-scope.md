# 43. 플랫폼·이동·입력 범위

- 상태: 확정
- 즉시 구현 명세 가능성: `READY`
- 관련 결정: ADR-0048

## 이동 모델

```text
월드 비율: 5 ft = 4 studs
권위 위치: 연속 좌표
권위 거리: 피트
권위 경로: 이동 가능 표면과 연결 그래프
규칙 격자: 없음
```

씬 편집기의 가상 격자는 벽·바닥·프리팹을 정렬하는 제작 커서일 뿐, 토큰 이동이나 D&D 거리 판정에 참여하지 않는다.

## 탐험

- 클릭 이동과 WASD 직접 이동을 모두 허용한다.
- 두 입력은 같은 이동 가능 표면, 차단, 험지와 서버 검증을 사용한다.
- WASD는 짧은 이동 의도를 반복 제출하고 서버가 승인한 위치로 보정한다.

## 전투

- 토큰 WASD 이동을 허용하지 않는다.
- 이동은 목적지 또는 경로를 클릭해 미리 본 뒤 확정한다.
- 경로에는 거리, 험지 비용, 남은 이동력과 예상 중단 지점을 표시한다.
- 이동 도중 반응이나 함정이 발생하면 해당 안전 경계에서 멈추고 후속 처리를 해결한다.
- 전투 중 WASD는 카메라 이동에 사용한다.

## 지원 기기

초기 제품은 PC 키보드·마우스 전용이다. 모바일·게임패드·터치 대응을 이유로 입력 계약이나 UI를 복잡하게 만들지 않는다.

## 제거 대상

- 항상 생성되는 5피트 논리 셀
- 격자 중심 강제 스냅
- 전투 토큰 WASD 직접 이동
- 모바일·게임패드 초기 대응
