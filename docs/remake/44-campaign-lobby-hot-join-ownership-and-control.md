# 44. 캠페인 로비·중도 참여·소유권·제어권

- 상태: 확정
- 즉시 구현 명세 가능성: `READY_WITH_DEFAULTS`
- 남은 기본값: 연결 종료 후 자동 인수 대기 시간, 세션 Ready 강제 시작 경고 시간
- 관련 결정: ADR-0049

## 데이터 구분

```text
CharacterOwner
→ 캐릭터의 영구적인 캠페인 소유자

ControlAssignment
→ 현재 세션에서 명령을 내릴 수 있는 사용자

SessionRole
→ DM | Player | Observer
```

Owner가 없는 캐릭터는 DM 관리 상태다. DM은 캠페인 관리 화면에서 Owner를 지정·변경·박탈할 수 있다.

## 로비

- 캠페인과 재개할 세션 상태를 표시한다.
- 접속 사용자, 로딩 상태, Ready 상태와 배정된 캐릭터를 보여준다.
- DM은 플레이어에게 Owner가 있는 캐릭터 또는 DM 관리 캐릭터를 배정할 수 있다.
- 캐릭터 Owner와 다른 사용자에게 임시 Controller를 줄 수도 있다.
- Observer로 입장할 수 있다.

## 중도 참여

```text
접속
→ 캠페인 권한 확인
→ 현재 세션 스냅샷 수신
→ 장면·Fog·Actor·Encounter 동기화
→ 미해결 Resolution 안전 경계 대기
→ Controller 배정
→ 플레이 시작
```

미해결 공격·주사위·저장 트랜잭션 중간에는 참가자를 삽입하지 않는다. 현재 결과가 확정된 후 최신 revision을 다시 받아 합류한다.

## 제어권 배정

DM UI에서 Actor를 선택하고 다음을 정한다.

- 대상 사용자
- 즉시 또는 예약 변경
- 이번 행동, 이번 턴, 이번 인카운터, 이번 세션, 회수 전까지의 기간
- 세션 종료 시 자동 반환 여부

플레이어는 자신이 Controller인 Actor만 명령할 수 있다. 소유권이 없는 NPC를 조작해도 NPC의 영구 데이터 관리 권한은 얻지 않는다.

## 연결 종료

- Actor와 Owner는 유지한다.
- 진행 중 명령은 안전하게 완료하거나 취소한다.
- 이후 입력은 캠페인 정책에 따라 일시정지, DM 인수, 위임 또는 턴 넘기기로 처리한다.
- 재접속하면 DM이 바꾸지 않은 한 기존 제어권을 복원한다.

## 저장

Owner 변경은 캠페인 영구 상태다. Controller와 기간 정책은 세션 상태다. 두 변경은 별도 명령과 감사 로그를 가진다.
