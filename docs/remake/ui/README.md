# UI 문서

화면 배치, 입력 문맥, 패널 상태와 사용자 피드백을 정의한다.

## 영역

- `common-input/`: RVTT 공통 입력 교과서
- `scene-editor/`: 씬 편집 화면과 조작
- `combat-hud/`: 전투 HUD와 행동 UI
- `character-sheet/`: 플레이어 캐릭터 시트
- `dm-workspace/`: DM 작업공간과 Quick Action
- `shared/`: 여러 UI가 공유하는 레이아웃과 컴포넌트

게임 규칙과 권위 상태는 `../systems/` 및 `../architecture/`를 따른다.
