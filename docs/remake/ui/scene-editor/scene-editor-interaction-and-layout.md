## 1. 목표

씬 편집기는 기능이 많아져도 현재 사용자가 무엇을 하고 있는지 명확해야 한다.

핵심 조작 상태는 다음 두 가지로 구분한다.

```text
선택 모드
→ 기존 오브젝트 선택과 편집

배치 모드
→ 선택한 도구, 에셋, 복제본 또는 청사진을 연속 배치
```

배치가 한 번 끝났다고 자동으로 선택 모드로 돌아가지 않는다. 사용자가 배치 모드를 명시적으로 종료할 때까지 같은 대상을 계속 배치할 수 있어야 한다.

---

## 2. 선택 모드와 배치 모드

### 2.1 선택 모드

선택 모드는 이미 씬에 존재하는 오브젝트를 다루는 기본 편집 상태다.

지원 기능:

- 클릭 단일 선택
- 3차원 박스 다중 선택
- 이동, 회전과 스케일 기즈모
- 인스펙터 수치 편집
- 삭제, 그룹, 잠금과 복제
- 선택 대상을 청사진으로 저장

### 2.2 배치 모드

배치 모드에서는 상시 가상 격자 커서에 현재 도구 또는 에셋의 고스트가 결합한다.

```text
도구 또는 에셋 선택
→ 배치 모드 진입
→ 커서를 따라 고스트 표시
→ 클릭 또는 드래그로 배치 확정
→ 같은 대상의 다음 고스트 유지
→ 배치 모드 종료 전까지 반복
```

벽, 프리팹, 기본 파트, 시작 지점과 청사진은 모두 같은 원칙을 사용한다.

배치 모드에서 한 번 배치했다고 선택 모드로 자동 전환하지 않는다.

### 2.3 모드 전환

다음 동작은 즉시 배치 모드로 들어간다.

- 에셋 브라우저에서 에셋 선택
- 건축 도구 선택
- 스포이드로 오브젝트 복사
- `Ctrl+D` 또는 복제 버튼 사용
- 청사진 선택

선택 도구를 선택하거나 배치 모드 종료 입력을 사용하면 선택 모드로 돌아간다. 정확한 종료 키와 버튼은 입력 문서에서 확정한다.

---

## 3. Shift 임시 스냅 해제

`Shift`를 누르고 있는 동안 현재 적용 중인 스냅을 일시적으로 해제한다.

이 규칙은 배치와 기즈모 편집에 공통으로 적용한다.

### 3.1 배치 모드

- 위치 격자 스냅
- 벽 끝점과 모서리 스냅
- 같은 높이 스냅
- 표면 정렬 보조
- 회전 각도 스냅

### 3.2 선택 모드 기즈모

- 이동 기즈모의 위치와 표면 스냅
- 회전 기즈모의 각도 스냅
- 스케일 기즈모의 크기 단위 스냅
- 파라메트릭 벽과 바닥 핸들의 길이 스냅

```text
Shift 누름
→ 현재 조작의 스냅만 임시 해제

Shift 해제
→ 기존 스냅 설정 즉시 복원
```

Shift는 저장된 스냅 설정을 변경하지 않는다. 해제 중에는 커서나 기즈모 옆에 `스냅 해제` 상태를 표시한다.

스케일과 회전도 이동과 동일하게 공통 `SnapService`를 통과해야 하며, 각 도구가 Shift 처리를 별도로 구현하지 않는다.

---

## 4. 스포이드

스포이드는 오브젝트의 외형만 복사하는 기능이 아니라 같은 대상을 다시 배치하는 빠른 진입 방식이다.

```text
스포이드 선택
→ 씬의 오브젝트 클릭
→ 해당 대상과 설정을 읽음
→ 즉시 배치 모드 진입
```

대상별 동작:

- 프리팹: 같은 프리팹과 배치 가능한 설정을 복사
- 기본 파트: 형태, 크기, 재질, 색상과 피벗 설정을 복사
- 벽: 벽 높이, 두께, 재질과 색상을 사용한 벽 도구로 진입
- 바닥: 두께, 재질과 색상을 사용한 바닥 도구로 진입
- 문과 창문: 같은 프리팹의 삽입 모드로 진입
- 청사진 인스턴스: 같은 청사진의 배치 모드로 진입

스포이드는 원본을 선택하거나 수정하지 않는다. 사용자가 배치 모드를 종료할 때까지 복사한 대상을 계속 배치할 수 있다.

---

## 5. 복제

선택한 오브젝트에서 `Ctrl+D`를 누르거나 인스펙터의 복제 버튼을 누르면 복제본을 즉시 생성하지 않는다.

```text
오브젝트 또는 그룹 선택
→ Ctrl+D 또는 복제 버튼
→ 원본 설정을 가진 복제 고스트 생성
→ 배치 모드 진입
→ 클릭할 때마다 복제본 배치
```

원본은 그 자리에 유지한다.

복제 고스트는 다음을 보존한다.

- 오브젝트 종류와 프리팹 ID
- 크기와 회전
- 재질과 색상
- 상호작용과 이동 프로필
- 그룹 내부의 상대 위치

다중 선택을 복제하면 선택 집합 전체를 하나의 배치 고스트로 다룬다. 배치 후에는 각 내부 오브젝트를 다시 개별 편집할 수 있어야 한다.

---

## 6. 오른쪽 인스펙터

오른쪽에는 선택 대상 또는 현재 배치 도구의 값을 직접 편집하는 인스펙터를 둔다.

기본 제공 항목:

- 위치 X, Y, Z
- 회전 X, Y, Z
- 크기 또는 스케일 X, Y, Z
- 재질과 색상
- 피벗과 배치 기준
- 스냅 간격과 회전 각도
- 이동과 상호작용 프로필

파라메트릭 오브젝트는 전용 값을 표시한다.

- 벽: 길이, 높이, 두께와 양 끝점
- 바닥: 두께와 다각형 점
- 계단: 폭, 시작 높이, 끝 높이와 단 수
- 영역: 폭, 길이, 높이와 효과 설정

숫자를 입력하면 고스트 또는 선택 대상이 즉시 갱신된다. 하나의 입력 확정은 실행 취소 이력에서 하나의 작업으로 기록한다.

다중 선택에서는 공통 값을 표시하고 값이 서로 다르면 `혼합` 상태를 표시한다.

---

## 7. 스마트 작업 추천

도구는 다음 작업을 자동 실행하지 않고, 현재 구조에서 유용한 후속 작업을 작은 추천 버튼으로 제시한다.

### 7.1 폐쇄된 벽 체인

- 내부 바닥 생성
- 천장 생성
- 방 그룹 생성

### 7.2 벽 연결 문제

- 가까운 벽 끝점 연결
- 작은 틈 닫기
- 겹친 벽 병합
- 교차점 정리

### 7.3 문과 창문

문이나 창문 고스트를 벽에 가까이 가져가면 벽 삽입 미리보기를 자동 표시한다.

추천은 사용자가 클릭해야 적용하며, 적용 결과는 하나의 실행 취소 작업으로 기록한다.

---

## 8. 측정 도구

측정 도구는 씬을 수정하지 않고 두 지점 사이의 수치를 표시한다.

기본 표시:

- 수평 XZ 거리
- 실제 3차원 거리
- Y 높이 차이
- stud와 ft 동시 표시

```text
수평 거리: 24 stud / 30 ft
높이 차이: 8 stud / 10 ft
실제 거리: 25.3 stud / 31.6 ft
```

측정점은 가상 격자 커서, 실제 표면, 벽 끝점과 오브젝트 피벗에 스냅할 수 있다. Shift를 누르면 측정 스냅도 일시적으로 해제한다.

측정선은 임시 표시가 기본이며, 필요하면 참고용 측정선을 씬 편집 메타데이터로 고정할 수 있다.

---

## 9. 편집 이력

단순 실행 취소와 다시 실행 외에 사용자 작업 단위의 편집 이력 창을 제공한다.

예시:

```text
벽 4개 생성
내부 바닥 생성
문 삽입
의자 6개 배치
벽 재질 변경
```

수십 개의 Part가 변경되더라도 사용자가 한 번 실행한 작업은 이력 한 줄로 표시한다.

기능:

- 최근 작업 목록
- 여러 단계 한 번에 되돌리기
- 되돌린 작업 다시 적용
- 현재 저장 시점 표시
- 자동 저장 지점 표시

씬 데이터가 다른 사용자나 서버 작업으로 변경된 경우에도 이력이 깨지지 않도록 편집 명령 ID와 영향을 받은 원본 오브젝트 ID를 기록한다.

---

## 10. 청사진

선택한 구조와 소품을 재사용 가능한 청사진으로 저장한다.

청사진에 포함되는 정보:

- 내부 오브젝트와 상대 위치
- 벽, 바닥과 문 연결
- 재질, 색상과 프리팹 설정
- 이동 의미 데이터
- 상호작용과 조명 설정
- 청사진 기준 피벗

청사진을 선택하면 전체 고스트가 상시 가상 격자 커서에 붙고 배치 모드로 들어간다.

지원 조작:

- Ctrl 수직 이동
- 회전과 회전 스냅
- Shift 임시 스냅 해제
- 표면 우선 배치
- 연속 배치

배치된 청사진은 하나의 불투명한 모델로 굳지 않는다. 내부 벽과 가구를 다시 선택하고 편집할 수 있는 원본 구조를 유지한다.

---

## 11. 3차원 셀렉션 박스

선택 모드에서 드래그해 3차원 선택 범위를 만든다.

### 11.1 1단계: XZ 범위

```text
마우스 누름
→ 가상 격자 또는 표면 위에서 시작점 확정
→ 누른 채 드래그
→ XZ 선택 사각형 미리보기
→ 마우스 놓기
```

마우스를 놓으면 XZ 위치와 폭, 길이가 잠긴다.

### 11.2 2단계: Y 높이

XZ 범위를 확정한 직후 포인터를 현재 위치에 잠그고 마우스의 수직 이동량만 읽는다.

```text
마우스를 위로 이동
→ 셀렉션 박스 상단 상승

마우스를 아래로 이동
→ 셀렉션 박스 상단 하강
```

이 단계에서는 실제 화면 커서가 화면 밖으로 빠져나가지 않는다. 커서를 계속 이동시키는 대신 상대적인 마우스 이동량으로 Y 높이를 조절한다.

셀렉션 박스 옆에는 다음 값을 표시한다.

- 폭 X
- 길이 Z
- 높이 Y
- 최소·최대 Y
- stud와 ft 환산

두 번째 클릭으로 3차원 범위를 확정하고, 취소 입력으로 전체 선택 박스를 폐기한다.

ViewY로 제외된 오브젝트와 편집 잠금 대상은 선택 후보에서 제외한다.

오브젝트가 선택 범위에 부분적으로 걸친 경우의 포함 기준은 후속 입력 문서에서 확정한다.

---

## 12. 자유 배치와 도킹이 가능한 창

씬 편집기의 기능 창은 고정된 한 가지 레이아웃을 강제하지 않는다.

대상 창 예시:

- 에셋 브라우저
- 인스펙터
- 편집 이력
- 청사진 브라우저
- 이동 판정 검토함
- 씬 계층과 그룹

지원 기능:

- 제목 표시줄을 드래그해 화면 안의 원하는 위치로 이동
- 창 크기 조절
- 화면 왼쪽, 오른쪽, 위쪽과 아래쪽 가장자리에 도킹
- 도킹 위치 미리보기
- 도킹 해제 후 다시 플로팅 창으로 사용
- 같은 가장자리에 여러 창을 탭으로 묶기
- 창 접기와 다시 열기
- 기본 레이아웃으로 초기화

레이아웃은 사용자별 로컬 설정으로 저장하며 다른 DM이나 플레이어 화면에는 영향을 주지 않는다.

기본 레이아웃은 다음을 제공한다.

```text
왼쪽
→ ViewY와 도구 목록

오른쪽
→ 인스펙터

하단
→ 퀵 바

별도 탭 또는 플로팅
→ 에셋, 이력, 청사진과 검토함
```

사용자는 모든 창을 옮길 수 있고 언제든 `레이아웃 초기화`로 기본 상태로 돌아갈 수 있다.

---

## 13. 제외하는 기능

이번 방향에서는 다음을 구현하지 않는다.

- 커서 아래 겹친 오브젝트 후보 순환
- 선택 대상을 제외한 씬 전체를 숨기는 선택 격리
- 마지막 명령을 별도 반복하는 기능

반복 배치는 배치 모드가 계속 유지되는 구조로 해결한다.

---

## 14. 구현 구조

공통 책임 후보:

- `EditorModeService`: 선택·배치 모드와 상태 전환
- `PlacementCursorService`: 상시 가상 격자 3D 커서
- `PlacementService`: 표면 우선 위치와 가상 평면 계산
- `SnapService`: 위치, 회전, 스케일과 Shift 임시 해제
- `TransformGizmoService`: 이동, 회전과 스케일 기즈모
- `SelectionVolumeService`: XZ 드래그와 Y 높이 선택 박스
- `InspectorService`: 속성 스키마와 수치 편집
- `EyedropperService`: 대상 설정 추출과 배치 모드 진입
- `DuplicatePlacementService`: 복제 고스트와 연속 배치
- `RecommendationService`: 후속 작업 추천
- `MeasurementService`: 임시·고정 측정
- `EditHistoryService`: 사용자 명령 단위 이력
- `BlueprintService`: 청사진 저장과 배치
- `PanelLayoutService`: 플로팅, 도킹과 레이아웃 저장

각 도구가 Shift, 인스펙터, 복제와 창 배치를 따로 구현하지 않는다.

## 15. 확정하는 방향

1. 편집기는 선택 모드와 배치 모드를 명확하게 구분한다.
2. 배치 모드는 명시적으로 종료할 때까지 같은 대상을 계속 배치한다.
3. Shift는 배치와 이동·회전·스케일 기즈모의 스냅을 일시적으로 해제한다.
4. 스포이드는 대상 설정을 읽고 즉시 해당 대상의 배치 모드로 들어간다.
5. Ctrl+D와 복제 버튼은 선택 대상의 복제 배치 모드로 들어간다.
6. 오른쪽 인스펙터에서 위치, 회전, 크기와 전용 파라미터를 숫자로 편집한다.
7. 폐쇄된 벽, 작은 틈과 문 삽입에 대한 스마트 추천을 제공한다.
8. stud와 ft를 함께 표시하는 측정 도구를 제공한다.
9. 사용자 작업 단위의 편집 이력 창을 제공한다.
10. 선택 구조를 다시 편집 가능한 청사진으로 저장하고 연속 배치할 수 있다.
11. 다중 선택은 XZ 드래그 후 포인터 잠금 상태에서 Y 높이를 지정하는 3차원 셀렉션 박스를 사용한다.
12. 편집 창은 이동, 크기 조절, 가장자리 도킹과 기본 레이아웃 초기화를 지원한다.
13. 겹친 후보 순환과 선택 격리는 구현하지 않는다.
