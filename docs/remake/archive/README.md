# Archive

현재 권위 문서로 사용하면 안 되지만 역사적 비교 가치가 있는 대체·폐기 문서를 보관한다.

Git 기록만으로 충분한 문서는 전체 본문을 별도로 복사하지 않을 수 있다. 보관 기록에는 원래 경로, 폐기 이유, 마지막 유효 범위와 대체 문서를 반드시 적는다.

## 구조

- [`discontinued/`](discontinued/README.md)
  - 현재 판단에 사용할 수 없고 역사적 의미만 남은 문서

## 규칙

- [`문서 수명주기와 Discontinuation 정책`](../DOCUMENT-LIFECYCLE-AND-DISCONTINUATION.md)
- Archive 문서는 권위 문서와 Guide의 Authority Documents가 될 수 없다.
- 새 기획을 시작할 때 Archive 결론보다 연결된 최신 대체 문서를 우선한다.
