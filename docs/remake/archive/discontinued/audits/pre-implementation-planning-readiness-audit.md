## 폐기 이유

이 Audit은 연속 이동, 전투 WASD, 로비·중도 참여, 소유권, 카메라, 인벤토리 사용자 흐름, 자동화 수준과 저장 정책을 미결정 또는 충돌 상태로 판정했다.

이후 ADR-0048~0053과 관련 Product·System 문서가 해당 제품 결정을 확정했다. 이어서 ADR-0054~0064와 최신 Architecture 문서가 공통 런타임 계약까지 크게 변경했으므로, 이 Audit의 우선순위와 상태표를 현재 판단에 사용하면 안 된다.
