공통 입력

  • Left: 선택 또는 표시된 기본 행동
  • Right: Context Action Table
  • Middle Drag: Camera Orbit
  • Q: 최상위 문맥 한 단계 취소
  • E: 현재 Confirm 하나 제출
  • ESC: Gameplay 의미 없음

권위·공개 경계

  • Preview와 Pending은 권위 결과가 아닙니다.
  • 권한 밖 Action·Entity·Document는 자리도 없습니다.
  • Player·Observer·DM은 별도 Projection을 봅니다.
