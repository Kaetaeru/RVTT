# ADR-0008: 상시 가상 격자 커서와 Ctrl 높이 조절

- 상태: 확정
- 결정일: 2026-08-03
- 관련 문서:
  - [`06-ingame-scene-editor-tools.md`](../systems/scene/ingame-scene-editor-tools.md)
  - [`ADR-0007`](ADR-0007-view-y-and-world-scale.md)

## 배경

RVTT의 씬 편집기는 실제 바닥이 없는 빈 공간에서도 벽, 바닥, 프리팹과 게임 영역을 배치할 수 있어야 한다.

이를 위해 실제 Part가 아닌 가상 격자 평면이 필요하다. 이 격자가 배치 고스트를 선택하거나 마우스를 누른 뒤에만 나타나면 사용자는 현재 편집 위치, 스냅 지점과 작업 높이를 미리 알 수 없다.

따라서 가상 격자는 배치 고스트의 부속물이 아니라 씬 편집기의 기본 3D 커서로 취급한다. 씬 편집 중에는 마우스 버튼을 누르지 않아도 커서가 표면 또는 가상 평면 위를 계속 따라다닌다.

## 결정

### 1. 모든 배치 도구가 하나의 공통 배치 시스템을 사용한다

가상 격자 커서는 벽 도구만의 기능이 아니다.

다음 도구가 같은 포인터 위치, 표면 판정, 가상 평면과 높이 조절 규칙을 공유한다.

- 벽
- 방과 바닥
- 문과 창문
- 계단과 경사로
- 프리팹
- 기본 파트
- 조명
- 험지, 위험과 이벤트 영역
- 시작 지점과 장면 전환 지점
- 이후 추가되는 배치형 편집 도구

각 도구는 자체적으로 마우스 위치와 높이 계산을 구현하지 않고 공통 `PlacementService`와 `PlacementCursorService`에 요청한다.

### 2. 가상 격자는 씬 편집 중 상시 표시되는 3D 커서다

씬 편집 모드에서 포인터가 월드 뷰포트 위에 있으면 가상 격자 커서를 항상 표시한다.

마우스 클릭이나 배치 고스트 활성화는 필요하지 않다.

커서는 다음 정보를 보여준다.

- 현재 스냅된 중심점
- 현재 작업 평면의 Y 높이
- 얇은 1 stud 기준선
- 굵은 4 stud, 즉 5피트 기준선
- 현재 도구가 배치될 방향 또는 피벗
- 배치 가능, 경고 또는 불가능 상태

화면 전체에 무한 격자를 그리지 않고 커서 주변의 제한된 격자 패치만 표시한다.

```text
마우스 이동
→ 표면 또는 가상 평면 위치 계산
→ 스냅 적용
→ 해당 위치로 격자 커서 이동
```

가상 격자 커서는 실제 Workspace Part가 아니다. 선택, 충돌, 이동, 시야와 포인터 광선을 가로채지 않는 클라이언트 전용 표시다.

### 3. 기본은 표면 우선 커서다

마우스 아래에 현재 도구가 사용할 수 있는 유효한 표면이 있으면 격자 커서를 그 표면 위에 표시한다.

```text
유효한 표면이 있음
→ 표면 위치와 방향을 우선 사용
→ 표면 위에 격자 커서 표시

유효한 표면이 없음
→ 현재 가상 수평 평면과 마우스 광선의 교차점 사용
→ 가상 평면 위에 격자 커서 표시
```

표면 우선 대상은 도구 종류에 따라 다르다.

- 바닥 부착 프리팹: 바닥과 수평 표면
- 벽 부착 프리팹: 벽과 수직 표면
- 천장 부착 프리팹: 아래쪽을 향한 표면
- 벽 도구: 수평 바닥 표면 또는 가상 수평 평면
- 문과 창문: 편집 가능한 벽
- 영역 도구: 수평 표면 또는 가상 수평 평면

ViewY로 제외된 오브젝트는 표면 후보와 포인터 판정에 참여하지 않는다.

### 4. 표면이 없을 때 가상 평면을 사용한다

가상 평면은 현재 클라이언트가 기억하는 수학적 수평 평면이다.

- 카메라 마우스 광선과 평면의 교차점으로 위치를 계산한다.
- 기본 편집 스냅을 적용한다.
- 서버나 다른 사용자에게 격자 오브젝트를 복제하지 않는다.
- 실제 바닥이 없어도 벽, 바닥과 오브젝트를 처음부터 배치할 수 있다.

씬을 처음 열었을 때 가상 평면의 기본 높이는 씬 기준 높이 또는 Y=0이다.

가상 평면의 현재 높이는 커서 표시를 위한 로컬 편집 상태이며 씬 원본 오브젝트가 아니다.

### 5. 배치 대상은 상시 커서에 붙는다

아무 배치 대상도 선택하지 않은 상태에서는 격자 커서만 표시된다.

벽, 프리팹, 바닥이나 영역 도구를 선택하면 해당 도구의 고스트가 이미 화면에 존재하는 격자 커서에 붙는다.

```text
씬 편집 진입
→ 가상 격자 커서 상시 표시

배치 도구 또는 에셋 선택
→ 고스트가 현재 격자 커서에 부착

마우스 이동
→ 격자 커서와 고스트가 함께 이동

클릭 또는 드래그 완료
→ 현재 커서 위치를 기준으로 배치 확정
```

클릭은 커서를 생성하거나 위치 계산을 시작하는 입력이 아니다. 클릭은 현재 커서가 이미 보여주는 위치를 확정하는 입력이다.

### 6. Ctrl + 수직 마우스 이동으로 클릭 전에 높이를 조절한다

배치 도구나 에셋 고스트가 선택된 상태에서 왼쪽 Ctrl을 누르고 마우스를 위아래로 움직이면 높이 조절 상태로 전환한다.

왼쪽 마우스 버튼을 누를 필요가 없다.

```text
일반 마우스 이동
→ 표면 또는 가상 평면 위에서 XZ 커서 이동

Ctrl + 수직 마우스 이동
→ 가상 격자 커서의 Y 높이 조절
→ 활성 고스트가 커서와 함께 이동

Ctrl 해제
→ 변경된 높이를 유지한 채 XZ 커서 이동으로 복귀

클릭
→ 현재 높이와 위치에 배치 확정
```

높이 조절 중에는 의도하지 않은 수평 이동을 줄이기 위해 XZ 위치를 잠그거나 입력 감도를 크게 낮춘다.

커서 옆에는 현재 높이를 stud와 피트로 함께 표시한다.

```text
Y: 8 stud / 10 ft
```

### 7. 높이는 현재 도구와 배치 작업에 속한다

전역 `BuildY` 슬라이더나 필수 작업 높이 관리 화면을 두지 않는다.

Ctrl 높이 조절로 변경한 평면은 현재 배치 도구와 현재 연속 배치 흐름에 적용한다.

- 같은 프리팹을 연속 배치하면 마지막 높이를 유지할 수 있다.
- 같은 벽 도구로 연속 벽을 만들면 현재 높이를 유지한다.
- 다른 도구나 에셋을 선택하면 다시 표면 우선 판정에서 시작한다.
- 사용자가 수동으로 높이를 조절한 현재 고스트는 배치가 끝날 때까지 표면에 자동 재부착하지 않는다.
- 현재 배치를 취소하면 확정하지 않은 고스트 상태도 취소한다.
- 배치 도구를 해제해도 씬 편집기의 격자 커서 자체는 계속 표시된다.

따라서 커서는 항상 존재하지만, 수동 높이 오프셋이 모든 후속 도구에 전역으로 강제되지는 않는다.

### 8. 벽 도구에서의 동작

블록스버그식 벽 도구를 선택하면 벽 시작점 커서가 즉시 가상 격자 커서 위에 표시된다.

사용자는 클릭 전에 커서를 움직이고 높이를 조절할 수 있다.

```text
벽 도구 선택
→ 격자 커서에 벽 시작점 표시

마우스 이동
→ 시작점 후보 이동

Ctrl + 수직 마우스 이동
→ 시작점과 가상 격자의 높이 조절

마우스 누름
→ 현재 커서 위치를 시작점으로 확정

누른 채 수평 드래그
→ 끝점과 길이 조절

마우스 놓기
→ 벽 확정
```

벽 드래그가 시작된 뒤 Ctrl 높이 조절을 사용하면 벽 전체의 바닥 높이를 이동한다.

- 벽 길이와 방향은 유지한다.
- 시작점과 끝점이 같은 Y만큼 함께 이동한다.
- 격자 커서도 새 벽 바닥 높이를 표시한다.

### 9. 바닥과 영역 도구에서의 동작

사각형 또는 다각형 도구를 선택하면 첫 지점 후보가 격자 커서를 계속 따라다닌다.

- 첫 지점 전: 표면 우선 커서 또는 가상 평면 사용
- 첫 지점 전 Ctrl 높이 조절: 작업 평면을 미리 이동
- 첫 지점 확정 후: 모든 후속 지점은 같은 수평 평면 사용
- 도형 확정 전 Ctrl 높이 조절: 도형 전체와 격자 커서를 함께 이동
- 도형 확정 후: 실제 높이와 원본 파라미터 저장

다각형의 각 점이 서로 다른 Y에 놓여 비정상적인 꼬임이 생기지 않게 한다.

### 10. 프리팹에서의 동작

프리팹을 선택하는 순간 고스트가 상시 격자 커서에 나타난다.

프리팹은 기본적으로 자신의 부착 프로필에 맞는 표면을 따른다.

Ctrl 높이 조절을 시작하면:

- 현재 표면에서 분리된다.
- 격자 커서와 고스트가 함께 수직 이동한다.
- 이후 수평 이동은 변경된 높이의 가상 평면을 따른다.
- 클릭으로 배치하기 전까지 회전과 스냅을 계속 사용할 수 있다.

벽이나 천장에만 붙을 수 있는 프리팹은 자유 공중 배치를 허용할지 프로필로 결정한다.

### 11. 스냅

커서 위치와 높이 조절 모두 편집 스냅을 사용한다.

초기 후보:

- 기본 XZ 스냅: 1 stud
- 세밀 XZ 스냅: 0.25 또는 0.5 stud
- 기본 높이 스냅: 0.5 stud
- 정밀 높이 스냅: 0.25 stud
- 큰 기준선: 4 stud = 5 ft

정확한 기본값과 정밀 조절 키는 입력 UI 문서에서 확정한다.

벽 끝, 바닥 상단과 인접 표면 높이에 가까워지면 자기식 높이 스냅을 제공할 수 있다.

### 12. ViewY와의 관계

ViewY와 가상 격자 커서 높이는 별개다.

- ViewY: 어디까지 보이고 마우스 판정에 참여하는가
- 가상 격자 커서: 현재 포인터와 배치 후보가 어느 위치에 있는가

가상 격자 커서를 ViewY보다 높게 올릴 수는 있지만, 커서나 고스트가 ViewY 위로 올라가 보이지 않게 되는 경우 경고를 표시하거나 ViewY 올리기를 제안한다.

ViewY를 움직여도 현재 격자 커서의 가상 평면 Y가 자동으로 바뀌지 않는다.

### 13. 구현 원칙

공통 배치 파이프라인은 씬 편집 중 지속적으로 다음 순서를 사용한다.

```text
마우스와 카메라 상태 변경
→ 포인터 질의
→ ViewY 필터
→ 도구별 유효 표면 검색
→ 표면 위치 또는 가상 평면 교차점 계산
→ 위치, 높이와 회전 스냅
→ 상시 격자 커서 갱신
→ 활성 도구가 있으면 고스트 갱신
→ 클릭 또는 드래그 완료 시 서버 검증과 확정
```

필요한 공통 책임:

- `PlacementCursorService`: 상시 격자 커서 표시와 상태 관리
- `PlacementService`: 표면과 가상 평면 위치 계산
- `PlacementPreviewService`: 선택한 도구와 에셋 고스트 표시
- `SnapService`: 위치, 높이와 회전 스냅
- `PointerQueryService`: ViewY와 도구별 필터
- `SceneCommandService`: 서버 확정 명령

가상 격자 커서를 거대한 투명 Part로 구현하지 않는다.

커서는 사용자 입력, 카메라, ViewY 또는 도구 상태가 변할 때만 갱신하며 Workspace 전체를 매 프레임 순회하지 않는다.

## 결과

RVTT의 씬 편집 모드에서는 마우스 버튼을 누르지 않아도 가상 격자 커서가 항상 현재 편집 위치를 보여준다.

평소에는 실제 표면 위를 따라다니고 표면이 없는 공간에서는 가상 수평 평면 위를 움직인다. 배치 도구나 에셋을 선택하면 고스트가 이 커서에 붙으며, Ctrl과 수직 마우스 이동으로 클릭 전에 원하는 높이에 옮길 수 있다.

이제 클릭은 커서를 활성화하는 입력이 아니라 이미 보이는 위치를 확정하는 입력이다.
