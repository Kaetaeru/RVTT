# ADR-0008: 표면 우선 배치와 Ctrl 수직 높이 조절

- 상태: 확정
- 결정일: 2026-08-03
- 관련 문서:
  - [`06-ingame-scene-editor-tools.md`](../06-ingame-scene-editor-tools.md)
  - [`ADR-0007`](ADR-0007-view-y-and-world-scale.md)

## 배경

RVTT의 씬 편집기는 실제 바닥이 없는 빈 공간에서도 벽, 바닥, 프리팹과 게임 영역을 배치할 수 있어야 한다.

이를 위해 실제 Part가 아닌 가상 격자 평면이 필요하지만, 사용자가 별도의 전역 `BuildY` 슬라이더를 계속 관리하게 만들면 편집 흐름이 복잡해진다.

TaleSpire식 조작처럼 배치 중인 대상의 높이를 직접 조절하고 가상 격자가 그 대상의 높이를 따라가게 하면, 평소에는 표면에 자연스럽게 놓고 필요한 순간에만 공중 배치를 수행할 수 있다.

## 결정

### 1. 모든 배치 도구가 하나의 공통 배치 시스템을 사용한다

가상 격자는 벽 도구만의 기능이 아니다.

다음 도구가 같은 배치 판정과 높이 조절 규칙을 공유한다.

- 벽
- 방과 바닥
- 문과 창문
- 계단과 경사로
- 프리팹
- 기본 파트
- 조명
- 험지, 위험과 이벤트 영역
- 시작 지점과 장면 전환 지점
- 이후 추가되는 배치형 편집 도구

각 도구는 자체적으로 마우스 위치와 높이 계산을 구현하지 않고 공통 `PlacementService`에 요청한다.

### 2. 기본은 표면 우선 배치다

마우스 아래에 현재 도구가 사용할 수 있는 유효한 표면이 있으면 그 표면을 우선한다.

```text
유효한 표면이 있음
→ 표면 위치와 방향 사용

유효한 표면이 없음
→ 가상 격자 평면 사용
```

표면 우선 대상은 도구 종류에 따라 다르다.

- 바닥 부착 프리팹: 바닥과 수평 표면
- 벽 부착 프리팹: 벽과 수직 표면
- 천장 부착 프리팹: 아래쪽을 향한 표면
- 벽 도구: 수평 바닥 표면 또는 가상 격자
- 문과 창문: 편집 가능한 벽
- 영역 도구: 수평 표면 또는 가상 격자

ViewY로 제외된 오브젝트는 표면 후보와 포인터 판정에 참여하지 않는다.

### 3. 표면이 없을 때 가상 격자를 사용한다

가상 격자는 실제 Workspace Part가 아니라 현재 클라이언트의 수학적 수평 평면이다.

- 카메라 마우스 광선과 평면의 교차점으로 위치를 계산한다.
- 기본 편집 스냅을 적용한다.
- 4 stud마다 5피트 기준선을 강조할 수 있다.
- 서버나 다른 사용자에게 격자 오브젝트를 복제하지 않는다.
- 선택, 이동과 게임 충돌을 가로채지 않는다.

가상 격자는 실제 바닥이 없어도 벽과 바닥을 처음부터 만들 수 있게 한다.

### 4. 배치 중 Ctrl + 수직 드래그로 높이를 조절한다

배치할 대상의 고스트가 활성화된 동안 왼쪽 Ctrl을 누르고 마우스를 위아래로 드래그하면 높이 조절 상태로 전환한다.

```text
일반 마우스 이동
→ 표면 또는 가상 격자 위에서 XZ 위치 조절

Ctrl + 수직 드래그
→ 배치 고스트의 Y 높이 조절
→ 가상 격자 평면이 고스트 높이를 따라 이동

Ctrl 해제
→ 변경된 높이를 유지한 채 일반 XZ 배치로 복귀
```

높이 조절 중에는 의도하지 않은 수평 이동을 줄이기 위해 XZ 위치를 잠그거나 입력 감도를 크게 낮춘다.

고스트 옆에는 현재 높이를 stud와 피트로 함께 표시한다.

```text
Y: 8 stud / 10 ft
```

### 5. 높이는 현재 배치 작업에 속한다

전역 `BuildY` 슬라이더나 필수 작업 높이 관리 화면을 두지 않는다.

Ctrl 수직 드래그로 변경한 높이는 우선 현재 배치 미리보기와 현재 도구의 연속 배치에 적용한다.

- 같은 프리팹을 연속 배치하면 마지막 높이를 유지할 수 있다.
- 새 도구를 선택하면 그 도구는 다시 표면 우선 판정에서 시작한다.
- 새 위치의 유효한 표면을 가리키면 해당 표면으로 자연스럽게 복귀한다.
- 사용자가 높이를 직접 조절한 동안에는 현재 고스트가 표면에 자동으로 다시 붙지 않는다.
- 배치를 취소하면 확정되지 않은 높이 변경도 취소된다.

따라서 도구마다 필요한 순간에만 높이를 바꾸며, 하나의 전역 높이가 모든 도구를 예상치 않게 지배하지 않는다.

### 6. 벽 도구에서의 동작

블록스버그식 벽 도구는 마우스 드래그로 길이를 만든다.

```text
마우스 누름
→ 시작점 확정
→ 수평 드래그로 끝점과 길이 조절
→ 마우스 놓기로 벽 확정
```

벽 미리보기 중 Ctrl 수직 드래그를 사용하면 벽 전체의 바닥 높이를 이동한다.

- 벽 길이와 방향은 유지한다.
- 시작점과 끝점이 같은 Y만큼 함께 이동한다.
- 가상 격자도 새 벽 바닥 높이로 이동한다.
- Ctrl을 놓으면 같은 높이에서 길이 조절을 계속한다.

시작점이 실제 표면에서 정해졌더라도 Ctrl 높이 조절을 시작한 순간부터 해당 미리보기는 표면에서 분리된다.

### 7. 바닥과 영역 도구에서의 동작

사각형 또는 다각형 도구는 첫 지점이 정해질 때 작업 평면을 잠근다.

- 첫 지점 전: 표면 우선 또는 가상 격자 사용
- 첫 지점 후: 모든 후속 지점은 같은 수평 평면 사용
- Ctrl 수직 드래그: 확정 전 도형 전체의 평면 높이 이동
- 도형 확정 후: 실제 높이와 원본 파라미터 저장

다각형의 각 점이 서로 다른 Y에 놓여 비정상적인 꼬임이 생기지 않게 한다.

### 8. 프리팹에서의 동작

프리팹은 기본적으로 자신의 부착 프로필에 맞는 표면을 따른다.

Ctrl 수직 드래그를 시작하면:

- 현재 표면에서 분리된다.
- 고스트와 가상 격자가 함께 수직 이동한다.
- 이후 수평 이동은 변경된 높이의 가상 격자를 따른다.
- 회전과 스냅은 계속 사용할 수 있다.

벽이나 천장에만 붙을 수 있는 프리팹은 자유 공중 배치를 허용할지 프로필로 결정한다.

### 9. 스냅

높이 조절에도 편집 스냅을 적용한다.

초기 후보:

- 기본 높이 스냅: 0.5 stud
- 정밀 높이 스냅: 0.25 stud
- 큰 단계 보조: 4 stud = 5 ft

정확한 기본값과 정밀 조절 키는 입력 UI 문서에서 확정한다.

벽 끝, 바닥 상단과 인접 표면 높이에 가까워지면 자기식 높이 스냅을 제공할 수 있다.

### 10. ViewY와의 관계

ViewY와 가상 격자 높이는 별개다.

- ViewY: 어디까지 보이고 마우스 판정에 참여하는가
- 가상 격자: 현재 배치 미리보기가 어느 Y 평면을 사용하는가

가상 격자를 ViewY보다 높게 올릴 수는 있지만, 고스트가 ViewY 위로 올라가 보이지 않게 되는 경우 경고를 표시하거나 ViewY 올리기를 제안한다.

ViewY를 움직여도 현재 배치 고스트와 가상 격자의 Y가 자동으로 바뀌지 않는다.

### 11. 구현 원칙

공통 배치 파이프라인은 개념적으로 다음 순서를 사용한다.

```text
포인터 질의
→ ViewY 필터
→ 도구별 유효 표면 검색
→ 표면 우선 위치 또는 가상 평면 교차점 계산
→ 위치와 회전 스냅
→ Ctrl 높이 오프셋 적용
→ 고스트 미리보기
→ 서버 검증과 확정
```

필요한 공통 책임:

- `PlacementService`: 표면과 가상 평면 위치 계산
- `PlacementPreviewService`: 로컬 고스트 표시
- `SnapService`: 위치, 높이와 회전 스냅
- `PointerQueryService`: ViewY와 도구별 필터
- `SceneCommandService`: 서버 확정 명령

가상 격자를 거대한 투명 Part로 구현하지 않는다.

## 결과

RVTT의 배치 도구는 평소에는 실제 표면에 자연스럽게 붙고, 빈 공간에서는 자동으로 가상 격자를 사용한다.

공중이나 다른 높이에 배치해야 할 때만 배치 고스트를 잡은 상태에서 Ctrl과 수직 드래그를 사용한다. 대상과 가상 격자가 함께 움직이므로 별도의 전역 높이 슬라이더 없이도 벽, 바닥, 프리팹과 영역을 원하는 높이에 배치할 수 있다.

이 조작은 모든 배치형 도구가 공유하지만, 높이 상태는 현재 배치 작업과 도구에 국한되어 다른 작업의 높이를 예상치 않게 변경하지 않는다.
