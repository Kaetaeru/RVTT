# ADR-0050: 자유 전술 카메라와 연출 우선순위

- 상태: 확정 · ADR-0088로 입력 세부 보강

- 최종 갱신일: 2026-08-06

## 결정

1. 플레이어와 DM은 토큰에 종속되지 않는 자유 전술 카메라를 사용한다.
2. 기본 입력은 PC 키보드·마우스를 기준으로 한다.
3. PC 기본 카메라 입력은 다음과 같다.

```text
마우스 휠 클릭 드래그
→ Yaw·Pitch Orbit

WASD
→ 카메라 기준 수평 이동

Wheel
→ Zoom

Ctrl+Wheel
→ Pivot Y 이동

F 또는 Space
→ 선택 Actor Frame
```

4. 오른쪽 클릭은 Context Action Table에 사용하며 카메라를 회전하지 않는다.
5. 탐험에서 WASD 토큰 직접 이동 모드가 켜진 경우에도 별도의 카메라 이동 입력을 제공한다.
6. 전투에서는 WASD가 카메라 이동에 사용된다.
7. ViewY, 지붕·상부 투명화, 카메라 충돌과 마우스 판정 통과는 카메라 Presentation 계층에서 처리한다.
8. 가림 보정은 Viewer의 Perception과 비밀 정보 공개를 우회하지 않는다.
9. 카메라 북마크와 Journal·Actor·Object Link의 초점 이동을 지원한다.
10. 턴 전환은 카메라를 강제로 이동하지 않는다. 현재 Actor를 강조하고 Frame 동작을 제안한다.
11. 자동 초점은 사용자 설정 또는 명시적인 Presentation Recipe에서만 허용한다.
12. DM은 플레이어에게 카메라 초점을 제안하거나 일시적으로 연출 카메라를 재생할 수 있지만, 지속 강제 추적은 명시적인 연출 동안만 허용한다.
13. 주사위, 반응창과 Presentation Recipe가 카메라를 사용할 때 공통 우선순위와 복귀 스택을 사용한다.
14. Text Input이 Focus된 동안 WASD와 카메라 단축키를 소비하지 않는다.

## 비목표

- NPC 대화 카메라와 대화 컷신 시스템
- 영화 편집기 수준의 타임라인
- 모바일 제스처와 게임패드 카메라
- 카메라 이동을 이용한 미인지 정보 공개

## 후속 관계

ADR-0088은 본 결정의 자유 전술 카메라 원칙을 유지하면서, 오른쪽 클릭을 Context Action Pointer로 확정하고 기존 오른쪽 클릭 Orbit 감각을 마우스 휠 클릭 드래그로 이동한다.
