# ADR-0050: 자유 전술 카메라와 연출 우선순위

- 상태: 확정
- 작성일: 2026-08-03

## 결정

1. 플레이어와 DM은 토큰에 종속되지 않는 자유 전술 카메라를 사용한다.
2. 기본 입력은 PC 키보드·마우스를 기준으로 한다.
3. 탐험에서 WASD 토큰 직접 이동 모드가 켜진 경우에도 별도의 카메라 이동 입력을 제공한다.
4. 전투에서는 WASD가 카메라 이동에 사용된다.
5. ViewY, 지붕·상부 투명화와 마우스 판정 통과는 카메라 표시 계층에서 처리한다.
6. 카메라 북마크와 저널·Actor·오브젝트 링크의 초점 이동을 지원한다.
7. DM은 플레이어에게 카메라 초점을 제안하거나 일시적으로 연출 카메라를 재생할 수 있지만, 지속 강제 추적은 명시적인 연출 동안만 허용한다.
8. 주사위, 반응창과 PresentationRecipe가 카메라를 사용할 때 공통 우선순위와 복귀 스택을 사용한다.

## 비목표

- NPC 대화 카메라와 대화 컷신 시스템
- 영화 편집기 수준의 타임라인
- 모바일 제스처와 게임패드 카메라
