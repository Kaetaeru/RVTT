# ADR-0019: 주문책은 아이템에 연결된 독립 영구 저장소다

- 상태: 확정
- 결정일: 2026-08-03
- 관련 문서:
  - [`ADR-0018`](ADR-0018-source-scoped-spellcasting-profiles.md)
  - [`12. 주문 획득·준비·시전 권한 모델`](../12-spell-acquisition-preparation-and-cast-access-model.md)
  - [`13. 주문책 저장소와 복사 모델`](../13-spellbook-repository-and-copying-model.md)

## 배경

주문책은 단순한 캐릭터의 `knownSpells` 목록이 아니다.

- 한 캐릭터가 기본 주문책과 예비 주문책을 동시에 가질 수 있다.
- 서로 다른 주문책은 서로 다른 주문을 담을 수 있다.
- 주문책은 분실, 보관, 양도, 약탈, 복제와 파괴가 가능하다.
- 주문을 준비한 상태와 책에 주문이 기록된 상태는 서로 다르다.
- 주문책 전체 데이터가 일반 아이템 이름이나 설명 문자열에 들어가면 검증, 복사와 마이그레이션이 어렵다.

반대로 주문책을 캐릭터에 영구 귀속하면 다른 캐릭터에게 넘기거나 장면의 보관함에 두는 상황을 자연스럽게 처리할 수 없다.

## 결정

각 주문책은 다음 두 요소로 구성한다.

```text
ItemInstance
└─ spellRepositoryId

SpellRepositoryRecord
└─ 해당 주문책에 기록된 SpellbookEntry 목록
```

`ItemInstance`는 책의 물리적 소유·보관 위치, 이름, 외형, 상태와 이동을 담당한다.

`SpellRepositoryRecord`는 책의 구조화된 주문 내용을 담당한다.

두 데이터는 안정적인 ID로 연결되며 하나의 영구 자산으로 취급한다.

## 소유와 수명

주문책은 특정 캐릭터에 직접 귀속되지 않는다. 현재 소유와 접근 권한은 연결된 `ItemInstance`의 보관 위치에서 결정한다.

가능한 보관 위치 예시:

- 캐릭터 인벤토리
- 캠페인 공동 보관함
- 장면의 상자 또는 오브젝트
- 다른 캐릭터나 NPC의 인벤토리
- 보관·분실 상태

따라서 주문책을 양도해도 `spellRepositoryId`와 기록된 주문은 유지된다.

주문책을 복제하면 같은 저장소를 공유하지 않고 새로운 `ItemInstance`와 새로운 `SpellRepositoryRecord`를 생성한다.

## 주문책에 저장하는 데이터

- 주문책 저장소 ID와 스키마 버전
- 연결된 아이템 인스턴스 ID
- 기록된 주문별 `SpellbookEntry`
- 각 기록의 주문 ID와 콘텐츠 버전
- 캐릭터 생성, 레벨업, 복사, 보상 등 기록 경로
- 기록 시각과 출처 참조
- 수정 revision과 상태

주문책에 저장하지 않는다.

- 현재 준비 여부
- 주문 슬롯과 무료 시전 소모량
- 주문 공격 보너스와 주문 내성 DC
- 주문의 전체 정의와 번역 문자열
- 현재 시전 가능한 경로
- 캐릭터의 집중과 지속 효과

준비 목록은 해당 직업의 `SpellcastingProfile` 상태가 소유한다.

## 접근과 분실

주문책을 소유하거나 규칙상 접근할 수 있을 때만 다음 작업에 사용할 수 있다.

- 새로운 주문 준비
- 주문책에서 직접 의식 시전
- 다른 책으로 주문 복사
- 레벨업 주문을 특정 책에 기록

이미 준비된 주문을 책 분실 즉시 삭제하지 않는다. 준비 상태 유지와 다음 준비 시점의 제한은 해당 `SpellcastingProfile`의 규칙 정책이 결정한다.

분실은 저장소 삭제가 아니다. 책을 회수하면 같은 기록을 다시 사용할 수 있다.

파괴는 명시적 규칙 작업으로 처리하며 연결된 저장소를 보관·복구 정책에 따라 비활성 또는 보관 상태로 전환한다.

## 기록 변경

주문책 항목은 클라이언트가 직접 추가하거나 삭제하지 않는다.

다음 서버 권한 트랜잭션만 주문책을 변경할 수 있다.

- 캐릭터 생성 시 기본 주문 기록
- 레벨업으로 얻은 주문 기록
- 다른 주문책이나 주문 두루마리에서 복사
- DM이 승인한 보상·복구·마이그레이션
- 명시적인 책 복제

각 작업은 주문 적격성, 책 접근 권한, 중복, 비용과 시간, 원본 소비 여부를 검증하고 원자적으로 확정한다.

## 결과

- 기본 책, 예비 책과 약탈한 책을 독립적으로 표현할 수 있다.
- 주문책의 양도, 장면 보관과 회수가 가능하다.
- 주문 준비와 물리적 책 내용을 분리할 수 있다.
- 책 복제 시 데이터가 의도치 않게 공유되지 않는다.
- 주문책을 삭제하거나 이동할 때 연결 데이터의 수명과 복구 정책을 함께 관리해야 한다.
