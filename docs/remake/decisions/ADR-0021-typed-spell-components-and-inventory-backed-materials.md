## 배경

주문 구성요소는 단순한 설명용 `V, S, M` 문자열이 아니다.

- 음성 구성요소는 말할 수 있는 상태를 요구한다.
- 동작 구성요소는 규칙에 맞는 손 사용 가능 상태를 요구한다.
- 물질 구성요소는 주문시전 도구나 구성요소 주머니로 대체할 수 있는 경우가 있다.
- 금전 가치가 명시된 재료는 일반 도구로 대체할 수 없다.
- 소비되는 재료는 시전 결제와 함께 실제 인벤토리에서 차감해야 한다.
- 아이템 시전, 특성, 메타마법과 기타 효과가 일부 구성요소를 제거하거나 변경할 수 있다.

모든 작은 재료를 개별 아이템으로 강제하면 플레이가 불필요하게 번거로워진다. 반대로 모든 재료를 무시하면 부활과 강력한 의식처럼 중요한 비용이 사라진다.

## 결정

주문 구성요소를 타입 있는 요구 조건으로 정의한다.

```text
SpellComponentRequirements
├─ VerbalRequirement
├─ SomaticRequirement
└─ MaterialRequirement[]
```

기본 물질 구성요소 정책은 다음과 같다.

### 가격이 없고 소비되지 않는 일반 재료

규칙상 유효한 주문시전 도구 또는 구성요소 주머니가 대신할 수 있다. 해당 재료를 인벤토리에 낱개로 생성하지 않는다.

### 가격이 명시된 재료

실제 인벤토리에서 요구 조건을 만족하는 재료를 소유하고 접근할 수 있어야 한다. 금화를 직접 차감해 재료 소유를 대신하지 않는다.

### 소비되는 재료

가격 유무와 관계없이 실제 인벤토리 항목 또는 재료 수량으로 추적하고, 시전 비용 확정 시 원자적으로 소비한다.

### 특정 고유 물체

정확한 아이템, 태그, 수량, 가치와 상태 조건을 구조화하여 검사한다. 주문 설명 문자열을 파싱하여 실행하지 않는다.

## 주문시전 도구와 구성요소 주머니

주문시전 도구와 구성요소 주머니는 각각 `ComponentSupplyCapability`를 제공한다.

이 기능은 다음을 명시한다.

- 어떤 `SpellcastingProfile`에서 사용할 수 있는가
- 손에 들거나 착용해야 하는가
- 어떤 일반 물질 요구를 대체할 수 있는가
- 가격 있는 재료와 소비 재료를 대체할 수 있는가
- 아이템 접근, 장착과 조율 조건

기본적으로 가격이 있거나 소비되는 재료는 대체하지 못한다. 예외는 명시적인 규칙 Capability로만 허용한다.

## 음성과 동작

음성과 동작 가능 여부는 자유 문자열 상태를 검사하지 않는다.

- 음성은 타입 있는 발화 가능 상태와 방해 효과를 검사한다.
- 동작은 손 점유, 장비, 상태 효과와 규칙 세트의 손 사용 정책을 검사한다.
- 물질 또는 도구를 든 손이 동작 구성요소도 수행할 수 있는지는 규칙 세트 정책에서 결정한다.
- 필요한 손을 만들기 위해 장비를 자동으로 버리거나 집어넣지 않는다.

특성이나 마법이 음성 또는 동작 구성요소를 제거하면 `ComponentOverrideCapability`가 이번 실행의 요구 조건을 변경한다. 원본 `SpellDefinition`은 수정하지 않는다.

## 구성요소 결제

구성요소 처리는 `CastCostPlan`에 포함한다.

```text
구성요소 요구 해석
→ 사용할 도구·주머니·재료 선택
→ 아이템 접근과 수량 검증
→ 소비 재료 예약
→ 주문 결제 commit point
→ 자원과 함께 원자적 소비
```

확정 전에 시전이 취소되면 재료 예약을 해제한다. 확정 이후 환불 여부는 해당 주문과 실행 규칙이 결정한다.

## 저장 원칙

`SpellDefinition`에는 구조화된 구성요소 요구를 저장한다.

캐릭터와 아이템 데이터에는 실제 소유한 도구, 주머니와 중요 재료만 저장한다.

다음을 저장하지 않는다.

- 주문별로 이미 구성요소를 만족했다는 영구 플래그
- 가격 없는 일반 재료의 무한 개별 목록
- 시전 가능 여부의 캐시를 권위 원본으로 사용한 값
- 주문 설명에서 추출한 비정형 비용 문자열

## DM 예외

DM은 규칙상 재료를 면제하거나 대체 재료를 승인할 수 있다.

이 경우 클라이언트가 요구 조건을 임의로 무시하지 않고, 구조화된 `DMComponentOverride` 또는 해당 실행에 한정된 승인 기록을 남긴다.

## 결과

- 발화, 손 사용과 재료 비용을 실제 규칙으로 검증할 수 있다.
- 작은 일반 재료를 모두 인벤토리화하지 않고도 주문시전 도구를 정확히 처리할 수 있다.
- 부활 재료와 소비되는 고가 재료는 실제 자산으로 유지된다.
- 아이템 시전과 구성요소 제거 특성을 원본 주문 복제 없이 지원할 수 있다.
- 인벤토리, 장비와 상태 효과 시스템이 주문 실행과 연결되어야 하므로 구현 경계가 넓어진다.

## 비결정 사항

다음은 후속 인벤토리 명세에서 구체화한다.

- 재료 묶음과 일반 아이템 인스턴스의 실제 타입
- 금전 가치 평가와 통화 변환 규칙
- 여러 재료 후보 중 자동 선택과 사용자 선택 방식
- 손에 들기, 꺼내기와 집어넣기의 행동 경제
- 캠페인별 간소화 정책을 제공할지 여부
