# ADR-0052: 2024 기본 콘텐츠, 롤백 상태, 청크 저장과 오디오 제외

- 상태: 확정
- 작성일: 2026-08-03

## 2024 기본 콘텐츠

`dnd5e-2024` 기본 규칙에 포함된 캐릭터 생성 콘텐츠를 모두 지원 대상으로 한다.

- 종
- 배경
- 직업
- 하위직업
- Feat
- 주문
- 장비와 일반 아이템
- 관련 성장 선택과 Weapon Mastery

각 콘텐츠는 가능한 범위에서 실행 가능하게 구현하며, 추가 공식 서적은 별도 SourcePack으로 추가한다.

## 자동화 등급

- `Executable`: 시스템이 판정과 결과 적용까지 처리
- `Guided`: 시스템이 절차와 선택지를 제공하고 DM 또는 플레이어가 중간 결정을 내림
- `Assisted`: 시스템은 굴림·기록·대상 보조만 제공하고 최종 세계 변화는 DM이 결정

이 등급은 기능의 품질 순위가 아니라 규칙의 자유도에 따른 실행 방식이다.

## 롤백

턴 롤백 시 권위 게임 상태를 해당 시점으로 되돌린다.

- Actor 위치·HP·자원·상태
- 오브젝트와 아이템
- Fog와 탐지
- 숨겨진 적과 비밀 요소
- 공개 여부와 제어권

이전 분기에서 보였던 Actor는 당시 보이지 않았다면 다시 복제하지 않는다. 전투 로그는 삭제하거나 과거 내용으로 되돌리지 않고, 롤백 경계와 무효화된 이후 기록을 표시한다.

## 저장

저장 단위가 플랫폼 한도를 초과하면 manifest와 여러 chunk로 분할한다.

- 각 chunk는 schemaVersion, revision, checksum과 순서를 가진다.
- manifest가 완전한 chunk 집합을 가리킨 뒤에만 새 저장본을 유효하게 표시한다.
- 누락·손상 chunk가 있으면 이전 정상 manifest로 복구한다.
- 장면, 저널, 타임라인과 대형 인벤토리는 독립 chunk 집합을 사용할 수 있다.
