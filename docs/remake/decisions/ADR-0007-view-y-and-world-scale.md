# ADR-0007: 연속 높이 ViewY와 월드 비율

- 상태: 확정
- 결정일: 2026-08-03
- 대체 범위: `06-ingame-scene-editor-tools.md`의 명시적 층 관리자와 현재 층 배치 방식
- 관련 결정:
  - ADR-0004 DM이 있는 발더스 게이트형 세션 조작
  - ADR-0005 성능, 안정성과 클린코드를 필수 기능으로 취급
  - ADR-0006 리그 없는 3D 토큰의 연속 이동

## 배경

명시적인 1층, 2층, 3층 구조는 정형 건물에는 편리하지만 동굴, 절벽, 다리, 비정형 고저차와 서로 어긋난 건축물을 편집할 때 제약이 된다.

RVTT의 씬은 하나의 연속된 3D 공간이며, 이동 가능한 표면도 고정된 층 번호가 아니라 실제 높이와 연결 관계로 관리한다.

또한 D&D 규칙의 거리와 Roblox 월드 좌표 사이에 하나의 고정 환산 기준이 필요하다.

## 결정

### 1. 명시적인 층 시스템을 사용하지 않는다

씬 데이터에는 편집용 `1층`, `2층`, `3층`을 필수 구조로 두지 않는다.

- 모든 오브젝트는 실제 월드 위치와 높이를 가진다.
- 바닥, 다리, 계단과 절벽은 절대 Y 좌표와 연결 정보로 관리한다.
- 건물 높이가 일정하지 않아도 같은 방식으로 편집한다.
- 층을 추가하거나 오브젝트를 다른 층으로 이동하는 작업은 존재하지 않는다.

오브젝트를 정리하기 위한 그룹, 잠금, 카테고리와 이름은 계속 지원하지만 높이 구간을 논리적인 층으로 강제하지 않는다.

### 2. 왼쪽 ViewY 슬라이더를 사용한다

편집 화면 왼쪽에 세로형 `ViewY` 슬라이더를 둔다.

슬라이더는 현재 사용자가 보고 선택할 수 있는 최대 높이인 `ViewYCut`을 제어한다.

```text
Y <= ViewYCut
→ 정상 표시
→ 마우스 선택과 배치 판정에 참여

Y > ViewYCut
→ 투명 또는 숨김 처리
→ 모든 포인터 판정에서 통과
```

사용자는 슬라이더를 내리면서 지붕, 위층 바닥과 상부 구조물을 걷어내고 내부 또는 아래쪽 공간을 직접 편집한다.

### 3. ViewY는 사용자별 로컬 보기 상태다

ViewY는 씬 원본을 수정하지 않는다.

- 사용자마다 서로 다른 ViewY 높이를 가질 수 있다.
- 씬 저장 데이터에 오브젝트의 가시성 변경으로 기록하지 않는다.
- 다른 참가자의 화면에 영향을 주지 않는다.
- 서버의 이동, 충돌, 시야와 게임 규칙 데이터를 바꾸지 않는다.

ViewY는 카메라 렌더링과 포인터 질의에만 적용되는 로컬 편집·관찰 상태다.

### 4. 마우스 판정은 상부 구조물을 완전히 통과한다

ViewY 위에 있는 오브젝트는 단순히 투명하게 보이기만 해서는 안 된다.

다음 포인터 기능 모두에서 제외한다.

- 선택
- 박스 선택 후보
- 벽과 바닥 시작점 지정
- 프리팹 표면 배치
- 문과 창문 벽 감지
- 페인트와 스포이드
- 지우개
- 이동 목적지 지정
- 상호작용 대상 지정

포인터 광선이 ViewY로 제외된 오브젝트를 맞히면 그 오브젝트를 건너뛰고 아래의 다음 유효 대상을 계속 찾는다.

전역 `CanQuery`를 변경하지 않는다. ViewY는 사용자별 상태이므로 공통 물리 속성을 수정하면 다른 사용자와 서버 판정에 영향을 줄 수 있다.

### 5. ViewY 경계의 표시

오브젝트의 높이 범위에 따라 세 상태로 표시한다.

- 경계 아래: 정상 표시와 정상 포인터 판정
- 경계 위: 높은 투명도 또는 숨김, 포인터 판정 제외
- 경계와 교차: 반투명 실루엣 또는 절단 표시, 포인터 판정 제외

초기 구현은 오브젝트 단위 반투명 처리로 시작할 수 있다. 벽과 대형 구조물은 이후 수직 구간 또는 절단용 표시를 지원할 수 있다.

### 6. 배치 높이

명시적인 현재 층 대신 다음 기준으로 배치 높이를 정한다.

1. 마우스가 가리키는 ViewY 아래의 유효 표면
2. 선택한 오브젝트의 높이
3. 사용자가 지정한 작업 높이 또는 수치 Y 값
4. 스냅 가능한 벽 끝점, 모서리와 인접 면

ViewYCut은 최대 표시·선택 높이이며, 모든 오브젝트를 그 높이에 강제로 배치하는 값은 아니다.

### 7. 월드 비율

RVTT의 기본 월드 비율은 다음과 같이 고정한다.

```text
5 ft = 4 stud
1 stud = 1.25 ft
1 ft = 0.8 stud
```

예시:

- Medium 토큰의 5피트 공간: 4 stud
- 이동속도 30피트: 24 stud의 경로 길이
- 근접 사거리 5피트: 4 stud
- 주문 사거리 60피트: 48 stud
- 반경 20피트: 16 stud

규칙 데이터는 피트 단위를 기준으로 저장한다. 렌더링, 위치와 월드 거리 계산 경계에서 중앙 환산 함수를 통해 stud로 변환한다.

각 기능이 `× 0.8` 또는 `÷ 1.25`를 제각각 작성하지 않는다.

### 8. 스냅과 격자

5피트 전술 격자를 표시하면 한 칸은 4 stud다.

편집 스냅은 전술 격자보다 세밀할 수 있다.

- 전술 격자: 4 stud
- 기본 편집 스냅 후보: 1 stud
- 세밀 편집 스냅 후보: 0.25 또는 0.5 stud

정확한 기본 스냅 값과 전환 UI는 후속 입력 문서에서 확정한다.

### 9. 성능 원칙

ViewY 슬라이더를 움직일 때 Workspace 전체를 매 프레임 순회하지 않는다.

- 편집 가능한 오브젝트를 높이 구간 또는 정렬된 인덱스로 관리한다.
- 슬라이더 경계를 새로 통과한 오브젝트만 표시 상태를 바꾼다.
- 로컬 투명도 변경을 사용해 서버 복제를 발생시키지 않는다.
- 포인터 질의는 ViewY 제외 대상을 건너뛰는 공통 필터를 사용한다.
- 파티클, 빔과 조명 등 비-Part 시각 요소도 ViewY 표시 규칙을 가진다.

## 결과

RVTT는 층 번호에 구속되지 않고 건물, 동굴, 절벽과 복잡한 고저차를 동일한 방식으로 편집할 수 있다.

ViewY를 내리면 상부 구조물이 시각적으로 걷히고 마우스 판정도 아래 공간으로 통과하므로, 사용자는 별도의 층 전환 없이 내부 구조를 직접 선택하고 제작할 수 있다.

월드 비율을 `5 ft = 4 stud`로 고정함으로써 이동, 사거리, 토큰 크기, 편집 격자와 맵 에셋이 하나의 일관된 기준을 공유한다.
