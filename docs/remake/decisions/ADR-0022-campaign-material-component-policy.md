# ADR-0022: 물질 구성요소 판정은 캠페인 규칙으로 선택한다

- 상태: 확정
- 결정일: 2026-08-03
- 관련 문서:
  - [`ADR-0020`](ADR-0020-typed-spell-resource-pools-and-explicit-cast-payments.md)
  - [`ADR-0021`](ADR-0021-typed-spell-components-and-inventory-backed-materials.md)
  - [`15. 주문 구성요소와 재료 인벤토리 계약`](../systems/rules/spell-components-and-material-inventory-contract.md)
  - [`16. 캠페인 물질 구성요소 정책`](../product/campaign-material-component-policy.md)

## 배경

물질 구성요소는 D&D 주문 규칙의 일부지만, 모든 캠페인이 재료와 주문시전 도구를 실제 플레이 자원으로 관리하지는 않는다.

특히 다음 처리는 세션 진행을 느리게 만들 수 있다.

- 주문시전 도구와 구성요소 주머니 확인
- 가격 있는 재료의 소유와 접근 판정
- 소비 재료의 수량, 예약과 차감
- 손에 든 도구와 재료 배정
- 부활이나 의식 재료의 구매와 보관 추적

RVTT가 물질 구성요소를 항상 강제하면 이를 사용하지 않는 캠페인은 불필요한 인벤토리 관리와 시전 차단을 겪게 된다.

반대로 구조 자체를 제거하면 물질 구성요소를 사용하는 캠페인과 공식 규칙 기반 콘텐츠를 지원할 수 없다.

## 결정

캠페인은 다음 설정을 가진다.

```text
CampaignRules
└─ spellcasting
   └─ materialComponentMode: ignore | enforce
```

새 캠페인의 기본값은 `ignore`다.

이 설정은 캠페인 전체에 적용하며 DM 권한을 가진 사용자만 변경할 수 있다. 플레이어별 물질 구성요소 정책은 두지 않는다.

## ignore 모드

`materialComponentMode = ignore`이면 모든 주문의 물질 구성요소 요구를 시전 가능 여부와 비용 판정에서 제외한다.

- 주문시전 도구와 구성요소 주머니를 요구하지 않는다.
- 가격 없는 일반 재료를 검사하지 않는다.
- 가격 있는 비소모 재료를 요구하지 않는다.
- 소비되는 재료를 예약하거나 차감하지 않는다.
- 특정 고유 물체 요구도 주문 시전 비용으로 검사하지 않는다.
- 물질 구성요소를 만족할 손이나 조작 슬롯을 배정하지 않는다.

다음 규칙은 계속 적용한다.

- 음성 구성요소
- 동작 구성요소
- 주문 슬롯, 무료 시전과 아이템 충전
- 행동, 보너스 행동과 반응 비용
- 주문 대상, 사거리, 집중과 지속시간
- 주문 경로가 요구하는 아이템 자체의 접근 조건

예를 들어 완드로 주문을 시전할 때 원본 주문의 물질 구성요소는 무시할 수 있지만, 완드 아이템 자체와 충전은 여전히 필요하다.

`SpellDefinition`의 구조화된 물질 구성요소 정보는 삭제하지 않는다. 주문 설명과 콘텐츠 데이터에는 유지하되, UI에는 캠페인이 해당 요구를 무시하고 있음을 표시할 수 있다.

## enforce 모드

`materialComponentMode = enforce`이면 `ADR-0021`과 `15-spell-components-and-material-inventory-contract.md`의 전체 검증 계약을 적용한다.

- 일반 재료는 유효한 주문시전 도구나 구성요소 주머니로 대체할 수 있다.
- 가격 있는 재료는 실제 인벤토리에서 검사한다.
- 소비 재료는 시전 결제 트랜잭션에서 예약하고 소비한다.
- 손, 장비, 도구 접근과 재료 상태를 서버가 검증한다.

## 실행 시점과 설정 변경

시전 실행을 생성할 때 현재 캠페인 정책을 실행 컨텍스트에 고정한다.

```text
RuleExecutionContext
└─ campaignRuleSnapshot.materialComponentMode
```

진행 중인 시전의 대상 선택, 승인 또는 결제 예약 도중 DM이 설정을 변경해도 해당 실행의 정책은 바뀌지 않는다.

설정 변경은 이후 생성되는 시전부터 적용한다.

`enforce`에서 `ignore`로 변경해도 이전에 소비된 재료를 환불하지 않는다.

`ignore`에서 `enforce`로 변경해도 기존 인벤토리에 재료를 자동 생성하거나 삭제하지 않는다. 이후 시전부터 현재 소유 상태를 사용한다.

## 저장과 검증

- 설정은 캠페인 권위 데이터에 저장한다.
- 설정 변경은 권한 검증, revision 증가와 캠페인 규칙 변경 로그를 남긴다.
- 클라이언트가 시전 요청마다 `ignoreMaterials = true`를 제출하게 하지 않는다.
- 서버는 캠페인 규칙 스냅샷으로 물질 구성요소 처리 여부를 결정한다.
- 저장 필드가 없는 기존 캠페인을 마이그레이션할 때는 `ignore`를 적용한다.

## 결과

- 물질 구성요소를 사용하지 않는 캠페인은 불필요한 재료와 도구 관리를 피할 수 있다.
- 공식 물질 구성요소 규칙을 원하는 캠페인은 전체 인벤토리 기반 검증을 사용할 수 있다.
- 음성·동작과 주문 자원 규칙은 물질 구성요소 설정과 독립적으로 유지된다.
- 주문 정의를 복제하거나 수정하지 않고 캠페인 규칙 해석 단계에서 정책을 적용할 수 있다.
- 캠페인 도중 정책을 변경할 수 있으므로 실행마다 규칙 스냅샷을 보존해야 한다.
