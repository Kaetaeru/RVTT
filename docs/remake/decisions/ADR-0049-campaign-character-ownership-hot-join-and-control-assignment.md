# ADR-0049: 캠페인 캐릭터 소유권, 중도 참여와 제어권 배정

- 상태: 확정
- 작성일: 2026-08-03

## 결정

1. 플레이어 캐릭터에는 캠페인 범위의 영구 `Owner`가 존재한다.
2. DM은 Owner를 생성·변경·박탈할 수 있다.
3. `Owner`와 현재 조작자인 `Controller`를 분리한다.
4. DM은 플레이어 캐릭터와 NPC의 Controller를 즉시 또는 안전 경계에서 배정·회수할 수 있다.
5. NPC의 영구 소유자는 캠페인 또는 장면이며, 플레이어에게 주는 것은 기본적으로 임시 제어권이다.
6. 진행 중 세션의 중도 참여를 허용한다.
7. 중도 참여자는 현재 권위 상태를 동기화한 뒤 안전 경계에서 플레이에 합류한다.
8. Observer는 캐릭터와 조작 권한 없이 허용된 카메라와 공개 정보만 사용한다.

## 안전 경계

제어권 변경 시점은 다음 중 선택한다.

- 즉시: 미해결 명령이 없을 때
- 현재 행동 해결 후
- 현재 턴 종료 후
- 다음 라운드 시작

진행 중인 판정이나 트랜잭션의 중간에 Controller를 바꾸지 않는다.

## DM 권한

DM은 플레이어 승인 없이 다음을 수행할 수 있다.

- Owner 변경 또는 박탈
- Controller 배정 또는 회수
- Observer 전환
- 연결 종료 Actor의 임시 인수
- 세션 종료 시 임시 NPC 제어권 반환

모든 변경은 감사 로그와 저장 revision을 남긴다.
