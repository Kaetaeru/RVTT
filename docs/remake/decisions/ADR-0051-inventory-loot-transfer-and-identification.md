# ADR-0051: 인벤토리·전리품·이전·식별 흐름

- 상태: 확정
- 작성일: 2026-08-03

## 결정

1. 아이템 규칙 정의, 실제 ItemInstance, 소유권, 위치와 장착 상태를 분리한다.
2. 아이템은 캐릭터 인벤토리, 컨테이너, 장면 바닥, 캠페인 보관함 중 하나의 권위 위치를 가진다.
3. 줍기·전리품 획득·플레이어 간 이전·DM 배분은 서버 권위의 소유권 이전 트랜잭션이다.
4. 동시에 같은 아이템을 가져가려는 요청은 revision과 예약으로 한 요청만 성공시킨다.
5. 전투 중 아이템 전달은 규칙 세트의 행동 비용과 거리 조건을 따른다.
6. 화폐는 아이템 묶음이 아니라 타입 있는 자원 원장으로 관리하되 UI에서는 인벤토리와 함께 표시한다.
7. 미확인 마법 아이템은 실제 정의와 플레이어에게 공개되는 표시 정의를 분리한다.
8. DM은 아이템 생성·이전·삭제·식별·수량 조정을 Override로 수행할 수 있고 모두 기록한다.
