# ADR-0048: 연속 무격자 이동, PC 전용 지원과 전투 WASD 금지

- 상태: 확정
- 작성일: 2026-08-03

## 결정

1. RVTT의 권위 이동 공간에는 5피트 논리 격자를 생성하지 않는다.
2. 토큰 위치, 경로, 점유, 사거리와 이동 비용은 연속 좌표와 피트 단위로 계산한다.
3. 월드 비율 `5 ft = 4 studs`는 유지한다.
4. 격자 오버레이를 플레이 기능으로 제공하지 않는다. 씬 편집기의 가상 배치 격자는 월드 제작 보조이며 규칙 이동 격자가 아니다.
5. 탐험에서는 클릭 이동과 WASD 직접 이동을 지원한다.
6. 전투에서는 WASD 토큰 이동을 금지하고 클릭 경로 이동만 지원한다.
7. 전투 중 WASD는 자유 카메라 이동에 사용한다.
8. 초기 지원 기기는 PC 키보드·마우스뿐이다. 모바일, 게임패드와 터치 UI는 초기 범위에 포함하지 않는다.

## 이유

항상 존재하는 논리 격자는 연속 이동의 장점을 약화하고, 셀 생성·질의·동기화 비용과 두 이동 모델의 불일치를 만든다. 전투 WASD는 이동력 확정, 반응, 함정과 경로 중단을 연속 입력 중 처리해야 하므로 조작성과 안정성을 동시에 악화시킨다.

## 구현 결과

- 내비게이션은 이동 가능 표면, 연결, 비용 영역과 차단 볼륨을 사용한다.
- D&D 거리와 범위는 stud를 피트로 변환해 계산한다.
- 전투 이동은 경로 미리보기 후 승인된 경로를 원자적 이동 구간으로 실행한다.
- 모든 문서와 에이전트 규약에서 `5피트 논리 격자`와 `전투 WASD 이동`을 제거해야 한다.
