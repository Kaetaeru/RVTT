# ADR-0009: 3차원 선택 박스 포함 판정 프리퍼런스

- 상태: 확정
- 결정일: 2026-08-03
- 관련 문서:
  - [`07-scene-editor-interaction-and-layout.md`](../07-scene-editor-interaction-and-layout.md)
  - [`ADR-0007`](ADR-0007-view-y-and-world-scale.md)

## 배경

씬 편집기의 3차원 선택 박스는 XZ 범위를 먼저 드래그하고, 이어서 상대 마우스 이동으로 Y 범위를 정한다.

오브젝트가 선택 박스 경계에 일부만 걸친 경우에는 두 가지 자연스러운 사용 방식이 있다.

- 넓은 영역을 빠르게 쓸어 담을 때는 조금이라도 닿은 대상을 모두 선택하는 방식이 편하다.
- 복잡한 구조에서 의도한 대상만 고를 때는 대상 전체가 박스 안에 들어와야 선택되는 방식이 안전하다.

하나의 방식만 강제하지 않는다.

## 결정

3차원 선택 박스의 포함 판정은 사용자별 편집 프리퍼런스로 제공한다.

### 교차 선택

```text
선택 박스 AABB와 대상 AABB가 조금이라도 교차
→ 대상 선택
```

용도:

- 넓은 영역을 빠르게 선택
- 작은 소품이 많은 구역 정리
- 선택 박스 경계에 걸친 대상을 놓치지 않기

### 완전 포함 선택

```text
대상 AABB 전체가 선택 박스 AABB 내부에 포함
→ 대상 선택
```

용도:

- 벽과 방이 밀집한 구역의 정밀 선택
- 인접 구조물을 실수로 포함하지 않기
- 선택 범위를 명확한 경계로 사용하기

## 프리퍼런스 동작

- 프리퍼런스는 사용자별 로컬 편집 설정으로 저장한다.
- 같은 씬을 편집하는 다른 사용자의 판정 방식에는 영향을 주지 않는다.
- 설정을 바꾸면 이후 만드는 선택 박스부터 새 방식을 적용한다.
- 현재 선택 결과를 설정 변경만으로 자동 재계산하지 않는다.
- 선택 박스 미리보기 중 현재 판정 방식을 짧게 표시한다.

예시:

```text
선택 방식: 교차
```

또는

```text
선택 방식: 완전 포함
```

## 판정 기준

초기 판정은 편집 대상의 월드 기준 AABB를 사용한다.

- ViewY로 제외된 대상은 판정하지 않는다.
- 잠긴 대상은 선택 후보에서 제외한다.
- 선택 불가로 표시된 VFX, 기즈모와 편집 보조물은 제외한다.
- 그룹과 파라메트릭 복합 오브젝트의 선택 단위는 별도 선택 계층 규칙을 따른다.

회전된 대상도 초기 버전에서는 OBB가 아니라 월드 AABB로 판정한다. 더 정밀한 OBB 판정은 실제 사용 중 AABB 오차가 문제가 될 때 검토한다.

## 결과

사용자는 빠른 대량 선택과 정밀한 완전 포함 선택 중 자신의 작업 방식에 맞는 판정을 선택할 수 있다.

이 결정은 `07-scene-editor-interaction-and-layout.md`의 미확정된 부분 교차 포함 기준을 대체한다.
