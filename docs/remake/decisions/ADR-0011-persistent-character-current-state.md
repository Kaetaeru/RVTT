# ADR-0011: 캐릭터 현재 상태의 영구 유지

- 상태: 확정
- 결정일: 2026-08-03
- 관련 문서:
  - [`02-core-session-loop.md`](../product/core-session-loop.md)
  - [`AGENTS.md`](../../../AGENTS.md)

## 배경

RVTT에는 짧은 휴식과 긴 휴식이 정식 게임 기능으로 존재한다.

세션 종료, 서버 종료 또는 재접속만으로 현재 HP와 자원이 자동 회복되면 휴식 규칙과 캠페인의 연속성이 무너진다.

## 결정

캐릭터의 현재 상태는 세션과 서버 수명을 넘어 영구 저장한다.

다음 상태를 포함한다.

- 현재 HP와 임시 HP
- 남은 주문 슬롯
- 직업, 종족, 재주와 아이템의 현재 자원 및 충전
- 사용한 히트 다이스
- 집중 상태
- 상태 효과와 소진
- 죽음 내성 성공·실패 상태
- 장비의 장착 및 활성 상태
- 지속 중인 효과와 남은 게임 규칙상 지속시간

세션 종료, 서버 이동, 연결 종료와 재접속은 이 값을 초기화하거나 회복하지 않는다.

상태는 다음과 같은 명시적인 게임 규칙 처리로만 변경된다.

- 짧은 휴식
- 긴 휴식
- 치유와 피해
- 자원 소비와 회복
- 효과의 시작과 종료
- DM의 명시적 판정 또는 수정
- 캐릭터 사망, 안정화와 부활 규칙

현실 시간의 경과만으로 상태 효과, 집중과 자원이 자동으로 변하지 않는다. 시간 기반 효과는 캠페인의 게임 시간과 해당 효과의 종료 규칙을 통해 처리한다.

## 저장 원칙

캐릭터 현재 상태는 캐릭터 영구 데이터와 함께 서버 권위로 저장한다.

- 클라이언트가 현재 상태를 원본으로 소유하지 않는다.
- 중요한 변경은 서버 검증 후 적용하고 저장 대기열에 기록한다.
- 재접속 시 마지막으로 확정 저장된 서버 상태를 복구한다.
- 저장 실패를 회복 또는 초기화로 대체하지 않는다.
- 중복 요청이 자원 중복 소비나 중복 회복을 만들지 않게 한다.

## 파생 데이터와의 구분

최대 HP, 최대 주문 슬롯, 최대 자원과 같은 파생 최대치는 직업 레벨, 능력치, 장비와 콘텐츠 정의에서 계산한다.

현재 HP, 남은 슬롯과 남은 자원은 계산 결과가 아니라 저장되는 현재 상태다.

파생 최대치가 변경될 때 현재 값의 조정 규칙은 해당 레벨업, 장비 또는 효과 명세에서 별도로 정의한다.

## 범위 밖

다음 항목의 저장 위치와 수명은 별도 결정으로 다룬다.

- 씬 안의 토큰 위치와 방향
- 현재 카메라 위치
- 열려 있는 UI와 로컬 편집 상태
- 일시적인 네트워크 요청과 미확정 행동
