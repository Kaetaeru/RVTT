## 배경

RVTT의 전투 HUD는 빠른 행동 선택을 위한 화면이다. 그러나 플레이어는 세션 중 자신의 전체 캐릭터 정보를 직접 열어 확인할 수 있어야 한다.

필요한 정보는 다음을 포함한다.

- 능력치, 내성 굴림과 기술
- 숙련 보너스, 영웅적 영감, 방어도, 우선권, 이동속도와 수동 지각
- HP, 임시 HP, 명중 주사위와 죽음 내성
- 무기, 피해 캔트립과 공격 수치
- 종족 특성, 직업 특성, Feat와 숙련
- 주문 능력치, 주문 명중, 주문 내성 DC, 주문 슬롯과 준비 주문
- 장비, 화폐, 조율, 언어, 외모, 성격과 배경 이야기

이 정보를 전투 HUD와 별도의 복제 데이터로 관리하면 HP, 주문 슬롯, 장비, 특성과 Hotbar가 서로 어긋난다. 반대로 종이 캐릭터 시트의 모든 칸을 직접 편집 가능하게 만들면 파생 수치와 공식 성장 규칙을 우회할 수 있다.

공식 D&D 2024 캐릭터 시트는 2페이지 구조를 사용한다.

```text
1페이지
→ 핵심 능력·전투 수치·공격·숙련·종족 특성·직업 특성·Feat

2페이지
→ 주문·주문 슬롯·장비·화폐·조율·언어·외모·배경과 성격
```

RVTT는 이 정보 구조와 익숙한 배치 원칙을 제품 기준점으로 사용한다. 다만 공식 시트의 일러스트, 장식 프레임, 로고, 글꼴과 기타 고유 그래픽 자산은 복제하지 않고 RVTT용으로 자체 제작한다.

## 결정

플레이어는 언제든 의미 동작 `OpenCharacterSheet`로 자신의 캐릭터 시트를 열 수 있다.

캐릭터 시트는 전투 HUD와 평행한 독립 UI 화면이지만, 별도 캐릭터 상태를 소유하지 않는다.

```text
CharacterRecord
+ DerivedValueSnapshot
+ CapabilitySnapshot
+ EquipmentState
+ SpellcastingState
+ VitalState
+ ResourceState
+ PresentationMetadata
→ CharacterSheetProjection
→ CharacterSheetView
```

동일한 서버 권위 상태가 다음 화면을 동시에 갱신한다.

```text
CharacterSheetView
Combat HUD
Hotbar
PartyRail
Tooltip
Roll Log
```

## 공식 형식 기반 기본 보기

기본 PC 보기는 공식 2024 시트의 2페이지 구조를 따른다.

```text
[기본 시트]
├─ 1페이지: 핵심 수치와 특성
└─ 2페이지: 주문·장비·인물 정보
```

16:9 화면에서는 다음 두 표시 방식을 지원한다.

```text
single_page
→ 한 페이지를 크게 표시하고 페이지 전환

double_spread
→ 두 페이지를 책처럼 나란히 표시
```

좁은 화면에서는 공식 정보 순서를 유지한 반응형 섹션 보기로 전환한다.

## 읽기·굴림·실행

시트는 단순한 문서가 아니라 실제 게임 상태와 연결된 인터페이스다.

- 능력 수정치, 내성 굴림과 기술을 선택하면 서버 권위 주사위 굴림을 요청한다.
- 무기, 피해 캔트립, 주문과 실행 가능한 특성을 선택하면 해당 Capability를 전투 HUD의 대상 지정 흐름으로 넘긴다.
- 실행 가능한 항목은 Hotbar에 고정하거나 제거할 수 있다.
- 피해, 회복, 주문 슬롯과 자원 변경은 기존 의미 명령과 검증을 사용한다.
- 주사위 결과는 ADR-0033의 프레젠테이션 게이트를 통과한다.

## 편집 권한

필드는 세 종류로 나눈다.

```text
freeform_owner_editable
→ 외모, 성격, 배경 이야기, 개인 메모 등

rule_bound
→ 능력치, 직업, 레벨, 종족, Feat, 숙련, 주문 습득 등
→ 캐릭터 생성·레벨업·재훈련·장비 변경 흐름만 허용

runtime_mutable
→ HP, 임시 HP, 영감, 죽음 내성, 주문 슬롯, 사용 횟수 등
→ 서버 검증 의미 명령만 허용
```

종이 시트처럼 보이더라도 규칙 수치를 임의 텍스트 입력으로 바꾸지 않는다.

DM은 권한이 있을 때 다음을 할 수 있다.

- 플레이어 시트를 읽기 전용으로 열기
- 규칙 변경 흐름을 대신 실행하기
- 명시적인 DM Override로 현재 HP·자원·임시 효과를 수정하기
- 변경 이력을 확인하기

## 전투 중 동작

캐릭터 시트를 열어도 EncounterSession은 멈추지 않는다.

- 기본은 전체 화면 또는 큰 오버레이로 연다.
- 선택적 `combat_side_sheet` 모드에서는 우측 또는 좌측 패널로 축소해 전장을 함께 본다.
- 반응, DM 승인, 재굴림과 주사위 공개처럼 우선순위가 높은 창이 열리면 시트는 어둡게 비활성화된다.
- 시트에서 행동을 선택하면 시트를 닫거나 축소하고 전투 HUD의 TargetingPlan으로 전환한다.
- 다른 Actor의 턴에는 읽기와 Hotbar 정리만 가능하며 규칙이 허용하지 않은 행동은 실행할 수 없다.

## 확장성

공식 시트에 없는 직업별 자원과 사용자 콘텐츠는 핵심 배치를 깨지 않고 확장 영역에 표시한다.

```text
SupplementalResourceStrip
FeatureDetailDrawer
CustomSectionRegistry
```

새 Feature, Feat, 장비, 주문과 사용자 정의 캐릭터 콘텐츠는 등록된 Presentation Metadata를 통해 다음에 자동 반영된다.

- 해당 시트 섹션
- 상세 툴팁
- 굴림 또는 실행 가능 여부
- Hotbar 고정 가능 여부
- 자원과 회복 정보

특정 직업이나 Feat 이름을 시트 UI 코드에 하드코딩하지 않는다.

## 개인정보와 공개 범위

- 플레이어는 자신의 전체 시트를 볼 수 있다.
- DM은 캠페인 권한에 따라 전체 시트를 볼 수 있다.
- 다른 플레이어에게는 공개 허용된 요약 정보만 표시한다.
- 배경 이야기, 개인 메모, 비밀 정체와 숨겨진 Feature는 필드별 공개 범위를 가질 수 있다.
- 권한 없는 클라이언트에 비공개 원문과 내부 식별자를 보내지 않는다.

## 결과

- 플레이어는 전투 HUD와 별개로 익숙한 공식 형식의 전체 캐릭터 시트를 직접 확인할 수 있다.
- 캐릭터 시트, Hotbar와 전투 상태가 하나의 권위 데이터에서 갱신된다.
- 종이 시트의 정보 구조를 유지하면서도 굴림, 행동 실행, 장비와 주문 관리가 연결된다.
- Feature, Feat와 새로운 공식 콘텐츠가 UI 코드 수정 없이 시트에 나타날 수 있다.
- 공식 고유 그래픽 자산을 복제하지 않고 RVTT 자체 시각 언어를 사용할 수 있다.
