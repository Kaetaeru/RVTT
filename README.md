# RVTT

Roblox 기반의 DM 중심 D&D/TRPG 가상 테이블탑 프로젝트입니다.

현재 새 RVTT 리메이크의 Runtime Architecture와 Main System Guide 통합을 마치고 Implementation Specs를 작성하는 단계입니다.

- [에이전트 작업 규약](AGENTS.md)
- [RVTT Remake 문서 허브](docs/remake/README.md)
- [현재 작업 순서](docs/remake/CURRENT-WORK-ORDER.md)
- [Main System Guide 허브](docs/remake/guides/README.md)
- [DM·플레이어 핵심 세션 흐름](docs/remake/product/core-session-loop.md)
- [Implementation Specs](docs/remake/specs/README.md)

저장소에서 기획이나 구현 명세를 시작하는 에이전트는 먼저 `AGENTS.md`, 현재 작업 순서, 관련 Main System Guide와 권위 문서를 읽어야 합니다.

> 리메이크 기획과 구현 명세는 `planning/rvtt-remake` 브랜치에서 진행합니다. 승인된 Implementation Spec 없이 Production Code를 작성하지 않습니다.
