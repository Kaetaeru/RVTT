- [Main System Guide 허브](docs/remake/guides/README.md)

처음 RVTT의 목표 플레이 방식을 확인하려면 **한눈에 보는 Player·DM 세션 흐름**부터 읽습니다. 역할별 자세한 설명은 Player Guide와 DM Guide에서 확인합니다.

기획이나 구현 명세를 시작하는 에이전트는 `AGENTS.md`, 현재 작업 순서, 관련 User Guide·Main System Guide와 권위 문서를 읽어야 합니다.

> 리메이크 기획과 구현 명세는 `planning/rvtt-remake` 브랜치에서 진행합니다. 승인된 Implementation Spec 없이 Production Code를 작성하지 않습니다.
