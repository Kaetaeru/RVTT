# RVTT

Roblox 기반의 DM 중심 D&D/TRPG 가상 테이블탑 프로젝트입니다.

현재 새 RVTT 리메이크를 구현하기 전에 제품 범위와 핵심 세션 흐름부터 다시 설계하고 있습니다.

- [에이전트 작업 규약](AGENTS.md)
- [RVTT Remake 기획 허브](docs/remake/README.md)

저장소에서 기획이나 구현을 시작하는 에이전트는 먼저 `AGENTS.md`와 관련 ADR을 읽어야 합니다.

> 리메이크 기획은 `planning/rvtt-remake` 브랜치에서 진행합니다. `main`의 기존 구현은 기획이 확정되기 전까지 유지합니다.
